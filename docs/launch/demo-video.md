# Демо-видео Rujarvis

Два ролика из одной съёмки: основной на 75–90 секунд (YouTube, VK Видео, Хабр,
README) и вертикальный на 20–30 секунд (Telegram, Shorts, Клипы).

Правило одно: **никакого монтажа, который прячет задержку.** Голосовой продукт
продаёт то, что человек видит своими глазами. Если команда выполнилась за
секунду — пусть это будет видно. Если агент думал полминуты — ускорить можно,
но с плашкой «×4».

## Подготовка

- Windows с чистым рабочим столом, Chrome, Telegram, Блокнот. Blender — для
  второго дубля.
- Хороший микрофон рядом, запись экрана с системным звуком (OBS). Голос Джарвиса
  должен быть слышен.
- В углу экрана — маленькая плашка с тем, что сказано (субтитры по речи).
- Claude Code залогинен. Проверить заранее: «что ты умеешь» открывает справочник.
- Для сцены с красной линией — тестовый репозиторий с незакоммиченной правкой
  (чтобы `git push` был реальным, но безвредным).

## Основной ролик (75–90 с)

| Время | Что на экране | Что говорим | Плашка |
| --- | --- | --- | --- |
| 0–4 | Рабочий стол, руки убраны от клавиатуры | — | «Руки не трогают клавиатуру» |
| 4–10 | Открывается Chrome | «Джарвис, открой хром» | «Мгновенно, без интернета» |
| 10–16 | Прокрутка страницы, закрытие вкладки | «Прокрути вниз… Закрой вкладку» | — |
| 16–24 | Сетка с номерами, клик по ячейке | «Покажи сетку… Нажми сорок пять» | «Клик по номеру» |
| 24–32 | Блокнот, диктовка, правка | «Режим диктовки. Привет, завтра встреча в пять. Удали последнее слово. Шесть. Конец диктовки» | «Диктовка с правкой» |
| 32–50 | Терминал с проектом, работает агент (×4) | «Найди, почему падают тесты, и почини» | «Дальше — Claude Code по вашей подписке» |
| 50–62 | Агент хочет сделать `git push`; Джарвис спрашивает вслух | Джарвис: «Агент хочет отправить изменения на GitHub. Разрешить?» — Вы: «Нет» | «Красная линия: без вашего «да» — ничего» |
| 62–70 | Агент долго что-то делает | «Стоп» — всё мгновенно останавливается | «„Стоп“ срабатывает всегда» |
| 70–80 | Экран с установкой в PowerShell | — | «Одна строка. Бесплатно. Открытый код» |
| 80–88 | Ссылка на GitHub и Telegram | — | `github.com/aisarus/Rujarvis` |

**Второй дубль (по желанию, 15 с, вставить после 32 с):** открытый Blender,
«Сделай её синей… Подними на три… Поверни на сорок пять» — объект меняется
мгновенно.

## Вертикальный ролик (20–30 с)

1. Крупно: «Говорю с компьютером по-русски. Без заученных команд.»
2. «Джарвис, открой хром» → окно открывается.
3. «Найди, почему падают тесты, и почини» → агент работает (×8).
4. Джарвис: «Разрешить отправить на GitHub?» — «Нет».
5. «Стоп.» Финальная плашка: «Rujarvis — бесплатно, открытый код».

## Чего не делать

- Не показывать то, что не работает стабильно с первого раза. Лучше три дубля
  одной честной сцены, чем склейка.
- Не обещать точность распознавания цифрой в ролике — цифры живут в README и статье.
- Не показывать реальные личные данные, почту, мессенджеры с перепиской.
