# Монтаж демо-ролика

Сценарий — [../demo-video.md](../demo-video.md). Здесь — сборка из сырых записей.

## Что нужно

- ffmpeg в PATH: `winget install Gyan.FFmpeg` (или путь к нему в переменной `FFMPEG`).
- Node.js — уже есть, если стоит Rujarvis.

## Как

1. Сырые записи из OBS положить в `raw/` (папка не попадает в git).
   Удобнее всего — одна сцена на файл: `scene01.mp4`, `scene02.mp4`…
   Если писали одним файлом, перед каждой сценой вслух: «сцена три»; после
   неудачного дубля: «плохо».
2. Заполнить `cuts.json`: для каждого куска — файл, начало и конец (`"0:12.5"`),
   ускорение (`"speed": 4`), текст плашки снизу (`plate`), сказанное — сверху
   (`said`), и `"vertical"`, если кусок идёт в вертикальную версию.
   Шаблон уже расписан по сценарию — меняются только файлы и тайминги.

   `"vertical": true` берёт тот же кусок целиком. Но вертикальный ролик
   обещан на 20–30 секунд, а те же куски дают 49, поэтому у него свои
   границы: `"vertical": { "to": "0:04" }` или `{ "speed": 8 }` —
   в вертикальной версии берётся то, что записано внутри, а остальное
   наследуется от куска. Сборка сверяет итог с обещанной длиной и говорит,
   если вышло не то.
3. Собрать:

   ```powershell
   node docs/launch/montage/make-video.mjs docs/launch/montage/cuts.json
   ```

   Готовые ролики — в `out/`: горизонтальный 1920×1080 и вертикальный 1080×1920.

## Поручить агенту

Откройте Claude Code в папке Rujarvis и скажите:

> Смонтируй демо-ролик по docs/launch/montage: записи в raw/. Найди в них сцены
> по сценарию (кадры — `ffmpeg -vf fps=1`, паузы — `silencedetect`), заполни
> тайминги в cuts.json, собери и покажи мне по кадру из каждой сцены.

На ускоренных кусках звука нет — только плашка «×N»: ускоренный голос звучит
нелепо. Всё, что не держится с первого раза, лучше переснять, чем прятать
монтажом.
