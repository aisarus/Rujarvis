# Установка и настройка

## Windows — одной командой

```powershell
irm https://raw.githubusercontent.com/aisarus/Rujarvis/main/install.ps1 | iex
```

С параметрами:

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/aisarus/Rujarvis/main/install.ps1))) -Language en -Autostart
```

| Параметр | Что делает |
| --- | --- |
| `-Language ru\|en` | Язык по умолчанию (меняется в настройках) |
| `-WhisperModel tiny\|base\|small\|turbo\|medium` | Модель распознавания; по умолчанию — по объёму памяти и видеокарте |
| `-InstallRoot <папка>` | Где жить Джарвису; по умолчанию `%LOCALAPPDATA%\Rujarvis` |
| `-Branch <ветка>` | Ветка репозитория; по умолчанию `main` |
| `-Autostart` | Запускать при входе в Windows |
| `-NoLaunch` | Не запускать приложение в конце |

Что делает установщик, по шагам:

1. Ставит через winget, если нет: Git и Node.js (22 или новее). pnpm —
   через corepack.
2. Клонирует исходники в `%LOCALAPPDATA%\Rujarvis\src` (повторный запуск —
   `git pull`).
3. Переносит данные прежней установки, если они есть: модели из
   `%APPDATA%\Interpreter`, память из `~\.openinterpreter\jarvis`. Ничего уже
   лежащего на новом месте не затирает.
4. `pnpm install` и `pnpm build` — секунды: сборка — это три бандла esbuild,
   нативных модулей нет.
5. `pnpm jarvis:setup` — скачивает модель распознавания и голос для языка.
6. Ярлык **Rujarvis** в меню «Пуск» ведёт прямо на приложение; оно
   запускается.

Компилятор C++, Rust и Bun не нужны. Раньше нужны были — на сборке C++
установка и падала.

## Первый запуск

Джарвис живёт в трее. При первом запуске открывается настройка из пяти шагов:
язык, Claude Code (вход — кнопкой «Войти», откроется терминал), модели речи
(если установщик их уже скачал, шаг просто проходит), проверка микрофона и
памятка по командам. Пока настройка не пройдена, Джарвис не слушает.

Всё это меняется потом в **трей → Настройки**:

| Вкладка | Что там |
| --- | --- |
| Общие | Язык и красные линии |
| Речь | Модель распознавания, голос (с кнопкой «Послушать»), микрофон |
| Агенты | Claude Code и Codex: установлены ли, выполнен ли вход; модель Claude |
| Папки и лог | Папка результатов, рабочая папка, что из речи писать в лог |
| Команды | Горячие клавиши и главные слова |

## Что остаётся на диске

Всё в одной папке, `%LOCALAPPDATA%\Rujarvis`:

```
src\       приложение
data\      settings.json, memory.json, journal.json, plan.json, notes.json,
           характер.md (постоянные указания агенту), runs\ (разбор прогонов)
logs\      jarvis.log и jarvis.1.log (ротация на 5 МБ)
models\    whisper\ — распознавание, voices\ — голоса
profile\   служебный профиль Electron
```

Результаты работы агента — в папке «Джарвис» (или «Jarvis») на рабочем
столе. Она создаётся при запуске вместе с разделами: Документы, Таблицы,
Презентации, Картинки, Видео, Аудио, Код, Архивы, Программы, Разное (в
английском режиме — Documents, Spreadsheets, …). Файлы одной задачи ложатся
подпапкой внутри раздела: `Картинки\Логотип кафе\`. Что агент оставил в
корне папки, после задачи раскладывается по разделам само; то, что вы
положили туда сами, не трогается.

В лог попадают команды, обращённые к Джарвису, и пути файлов, которые трогал
агент. Диктовка и речь, обращённая не к нему, не пишутся — только их длина.
Настройка «Что из речи писать в лог» меняет это: «ничего» или «всё» (для
разбора, когда Джарвис не слышит). Прежде чем приложить лог к issue,
прочитайте его.

## Переменные окружения

| Переменная | Что делает |
| --- | --- |
| `JARVIS_HOME` | Перенести всю папку Джарвиса |
| `JARVIS_OUTPUT_DIR` | Папка результатов (важнее настройки) |
| `JARVIS_DESKTOP_MCP` | Свой запуск MCP-сервера рабочего стола вместо собранного `dist\jarvis\desktop\mcp.cjs` |
| `JARVIS_CLAUDE_PATH`, `JARVIS_CODEX_PATH` | Где лежат CLI, если не в обычных местах |
| `JARVIS_CUA_DRIVER` | Путь к `cua-driver.exe` для инструментов окон (`window_*`) |
| `JARVIS_GPU_STT` | Адрес сервера whisper.cpp — распознавание на видеокарте |
| `ELEVENLABS_API_KEY` | Облачное распознавание (звук уходит в ElevenLabs) |

Хук красных линий запускается через `node` из `PATH`. Если `node` не найден,
в логе будет «красные линии только на фразах», и агент работает без оболочки.

## Сборка из исходников (любая ОС)

```bash
git clone https://github.com/aisarus/Rujarvis.git
cd Rujarvis
pnpm install
pnpm build
pnpm jarvis:setup            # модели; -- --language en для английского
pnpm start
```

На Linux и macOS голос, настройки, разговор и работа Claude Code работают;
драйвер рабочего стола (мышь, клавиатура, окна через PowerShell), запуск и
закрытие программ — только на Windows.

## Проверки

```bash
pnpm typecheck
pnpm test
pnpm jarvis:roundtrip               # голос по кругу: синтез → распознавание → команда
pnpm jarvis:roundtrip -- --en
pnpm jarvis:health                  # Windows: сборка, данные, MCP-сервер вживую
pwsh -NoProfile -File scripts/check-install-script.ps1   # установщик
```
