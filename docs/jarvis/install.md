# Установка и настройка

## Windows — одной командой

```powershell
$f = "$env:TEMP\rujarvis-install.ps1"; irm https://raw.githubusercontent.com/aisarus/Rujarvis/main/install.ps1 -OutFile $f; & $f
```

С параметрами:

```powershell
$f = "$env:TEMP\rujarvis-install.ps1"; irm https://raw.githubusercontent.com/aisarus/Rujarvis/main/install.ps1 -OutFile $f; & $f -Language en -Autostart
```

Скрипт сначала скачивается в файл, а не выполняется из строки. Причина
прикладная: у него BOM, без которого Windows PowerShell 5.1 читает русские
сообщения как ANSI и не разбирает файл вовсе. Но `irm | iex` получает файл
СТРОКОЙ, и BOM попадает в её начало — открывающий комментарий перестаёт
распознаваться, и установка падает с «Непредвиденная лексема». Через файл BOM
работает как задуман, и параметры пишутся обычным способом.

| Параметр | Что делает |
| --- | --- |
| `-Language ru\|en` | Язык по умолчанию (меняется в настройках) |
| `-WhisperModel tiny\|base\|small\|turbo\|medium` | Модель распознавания; по умолчанию — по объёму памяти и видеокарте |
| `-InstallRoot <папка>` | Где жить Джарвису; по умолчанию `%LOCALAPPDATA%\Rujarvis` |
| `-Branch <ветка>` | Ветка репозитория; по умолчанию `main` |
| `-Autostart` | Запускать при входе в Windows |
| `-NoLaunch` | Не запускать приложение в конце |

Что делает установщик, по шагам:

1. Ставит через winget, если нет: Git и Node.js (22 или новее). pnpm —
   через corepack.
2. Клонирует исходники в `%LOCALAPPDATA%\Rujarvis\src` (повторный запуск —
   `git pull`). Если Джарвис этой установки запущен, закрывает его — по
   точному пути его `electron.exe`, чужие программы не трогает — и в конце
   запускает заново: иначе новый код не заработал бы до перезапуска.
3. Переносит данные прежней установки, если они есть: модели из
   `%APPDATA%\Interpreter`, память из `~\.openinterpreter\jarvis`. Ничего уже
   лежащего на новом месте не затирает.
4. `pnpm install` и `pnpm build` — секунды: сборка — это три бандла esbuild,
   нативных модулей нет.
5. `pnpm jarvis:setup` — скачивает модель распознавания и голос для языка.
6. Скачивает драйвер окон [cua-driver](https://github.com/trycua/cua) (MIT)
   закреплённой версии и сверяет SHA-256. Не скачался — установка идёт
   дальше, выключаются только инструменты окон (`window_*`).
7. Ярлык **Rujarvis** в меню «Пуск» ведёт прямо на приложение; оно
   запускается.

Компилятор C++, Rust и Bun не нужны. Раньше нужны были — на сборке C++
установка и падала.

## macOS — одной командой

Терминал: **Cmd+Пробел**, набрать «Терминал», Enter. Вставить строку целиком:

```bash
f=/tmp/rujarvis-install.sh; curl -fsSL https://raw.githubusercontent.com/aisarus/Rujarvis/main/install.sh -o "$f" && bash "$f"
```

Homebrew, Git и Node.js ставятся сами, если их нет (пароль спросят один раз,
если нужен Homebrew). Приложение **Rujarvis** появляется в `~/Applications`.

### Какие окна спросит macOS и что нажать

Каждое разрешение macOS спрашивает один раз и отдельно. Названия пунктов —
по документации Apple; на живом маке тексты окон не сверены.

| Когда | О чём спросит | Что нажать |
| --- | --- | --- |
| Первая фраза | Доступ к **микрофону** (система может назвать приложение Electron) | «Разрешить» |
| «Войти» в настройке | Можно ли Rujarvis управлять приложением **«Терминал»** | «Разрешить» (или «ОК») |
| Первая команда про окна, мышь, клавиши | **Универсальный доступ** | «Открыть Системные настройки» → включить Rujarvis |
| Первый снимок окна | **Запись экрана** | То же: включить Rujarvis, затем перезапустить его |

Нажали «Не разрешать» на вопросе про Терминал — окно входа не откроется.
Включить можно в **Системные настройки → Конфиденциальность и безопасность →
Автоматизация → Rujarvis → «Терминал»**. Или войти самому: в Терминале
`claude auth login` (для Codex — `codex login`), потом «Проверить» в
настройке. Подсказка под кнопкой «Войти» на маке говорит то же самое.

Без «Универсального доступа» macOS не падает, а **молча ничего не делает** —
поэтому Джарвис спрашивает это разрешение сам, до первой операции.

## Первый запуск

Джарвис живёт в трее. При первом запуске открывается настройка из пяти шагов:
язык, Claude Code (вход — кнопкой «Войти», откроется терминал), модели речи
(если установщик их уже скачал, шаг просто проходит), проверка микрофона и
памятка по командам. Пока настройка не пройдена, Джарвис не слушает.

Всё это меняется потом в **трей → Настройки**:

| Вкладка | Что там |
| --- | --- |
| Общие | Язык и красные линии |
| Речь | Модель распознавания, голос (с кнопкой «Послушать»), микрофон |
| Агенты | Claude Code и Codex: установлены ли, выполнен ли вход; модель Claude; своя модель (Ollama, LM Studio, llama.cpp) вместо подписки |
| Папки и лог | Папка результатов, рабочая папка, что из речи писать в лог |
| Команды | Горячие клавиши и главные слова |

## Что остаётся на диске

Всё в одной папке, `%LOCALAPPDATA%\Rujarvis`:

```
src\       приложение
data\      settings.json, memory.json, journal.json, plan.json, notes.json,
           характер.md (постоянные указания агенту), runs\ (разбор прогонов)
logs\      jarvis.log и jarvis.1.log (ротация на 5 МБ)
models\    whisper\ — распознавание, voices\ — голоса
profile\   служебный профиль Electron
```

Результаты работы агента — в папке «Джарвис» (или «Jarvis») на рабочем
столе. Она создаётся при запуске вместе с разделами: Документы, Таблицы,
Презентации, Картинки, Видео, Аудио, Код, Архивы, Программы, Разное (в
английском режиме — Documents, Spreadsheets, …). Файлы одной задачи ложатся
подпапкой внутри раздела: `Картинки\Логотип кафе\`. Что агент оставил в
корне папки, после задачи раскладывается по разделам само; то, что вы
положили туда сами, не трогается.

В лог попадают команды, обращённые к Джарвису, и пути файлов, которые трогал
агент. Диктовка и речь, обращённая не к нему, не пишутся — только их длина.
Настройка «Что из речи писать в лог» меняет это: «ничего» или «всё» (для
разбора, когда Джарвис не слышит). Прежде чем приложить лог к issue,
прочитайте его.

## Удаление

`uninstall.ps1` (Windows) и `uninstall.sh` (macOS) лежат в `src`; команды — в
`README.md`. По шагам: закрывает Джарвиса этой установки (по точному пути его
Electron), убирает ярлыки и автозапуск, удаляет папку установки целиком.
Удаляет только папку с именем `Rujarvis`, в которой правда лежит Джарвис
(`src\app\main.ts` или `data`). Папку результатов на рабочем столе,
`~\.claude` и `~\.codex` не трогает. В CI на обеих системах: установка →
удаление → не осталось ничего, кроме названного.

## Переменные окружения

| Переменная | Что делает |
| --- | --- |
| `JARVIS_HOME` | Перенести всю папку Джарвиса |
| `JARVIS_OUTPUT_DIR` | Папка результатов (важнее настройки) |
| `JARVIS_DESKTOP_MCP` | Свой запуск MCP-сервера рабочего стола вместо собранного `dist\jarvis\desktop\mcp.cjs` |
| `JARVIS_CLAUDE_PATH`, `JARVIS_CODEX_PATH` | Где лежат CLI, если не в обычных местах |
| `JARVIS_CUA_DRIVER` | Свой `cua-driver.exe` вместо скачанного установщиком |
| `JARVIS_GPU_STT` | Адрес своего сервера whisper.cpp. Без него Джарвис поднимает свой, если распознавание на видеокарте поставлено (`pnpm jarvis:gpu-stt`) |
| `ELEVENLABS_API_KEY` | Ключ облачного распознавания. Работает только вместе с переключателем «Где распознаётся речь → в облаке» в настройках (вкладка «Речь»); звук тогда уходит в ElevenLabs |

Хук красных линий запускается через `node` из `PATH`. Если `node` не найден,
в логе будет «красные линии только на фразах», и агент работает без оболочки.

## Сборка из исходников (любая ОС)

```bash
git clone https://github.com/aisarus/Rujarvis.git
cd Rujarvis
pnpm install
pnpm build
pnpm jarvis:setup            # модели; -- --language en для английского
pnpm start
```

На Linux голос, настройки, разговор и работа Claude Code работают; драйвера
рабочего стола там нет. На macOS окна, клавиши и снимки идут через System
Events и CoreGraphics — см. раздел про macOS выше и `README.md`.

## Проверки

```bash
pnpm typecheck
pnpm test
pnpm jarvis:roundtrip               # голос по кругу: синтез → распознавание → команда
pnpm jarvis:roundtrip -- --en
pnpm jarvis:health                  # Windows: сборка, данные, MCP-сервер вживую
pwsh -NoProfile -File scripts/check-install-script.ps1   # установщик
```
