# Тестер на маке: первые десять минут

Коротко и по порядку. Подробности — в [`install.md`](install.md).

## 1. Установка — одна строка в Терминале

Терминал: **Cmd+Пробел** → «Терминал» → Enter. Вставить строку целиком:

```bash
f=/tmp/rujarvis-install.sh; curl -fsSL https://raw.githubusercontent.com/aisarus/Rujarvis/main/install.sh -o "$f" && bash "$f"
```

Homebrew, Git и Node.js (с ним npm) ставятся сами, если их нет. В конце
появится **Rujarvis** в `~/Applications` и ярлык на Рабочем столе.

**Сначала установщик, потом Codex.** На чистом маке нет Node.js, и
`npm install -g @openai/codex` до установки отвечает «command not found»
(живой мак тестера, 27.09.2026).

Если Homebrew поставил наш установщик, Терминал его пока не видит — ни в
этом окне, ни в новых: установщик включает его только внутри себя и в
`~/.zprofile` не пишет. В конце установки он сам подскажет строку; на маке
с M1–M4 это

```bash
eval "$(/opt/homebrew/bin/brew shellenv)"
```

— в каждом новом окне, где нужны `npm`, `codex` или `pnpm`. На маке с Intel
не нужно. Самому Rujarvis это не требуется: ярлык находит node и Codex сам.

Агент нужен хотя бы один. Если стоит только Codex — этого достаточно:

```bash
codex login status
```

Нет Codex — `npm install -g @openai/codex`, затем `codex login`.

## 2. Что разрешить в Системных настройках

Первый запуск Rujarvis сам спросит микрофон и откроет окна про остальное.
Всё лежит в **Системные настройки → Конфиденциальность и безопасность**; в
списках Rujarvis может называться **Electron**.

| Раздел | Зачем | Если не дать |
| --- | --- | --- |
| **Микрофон** | голос | Джарвис не слышит вовсе |
| **Универсальный доступ** | окна, мышь, клавиши | команды «сделаны», но ничего не происходит |
| **Запись экрана** | снимки окон | агент не видит экран |
| **Автоматизация → Терминал** | кнопка «Войти» в мастере | окно входа не откроется (войти можно и самому: `codex login`) |

После того как включили Универсальный доступ или Запись экрана — выйти из
Rujarvis (значок в строке меню → Выйти) и открыть снова.

## 3. Проверка — одна команда

```bash
cd ~/Library/Application\ Support/Rujarvis/src && pnpm jarvis:preflight
```

По каждому звену — **прошло**, **НЕ ПРОШЛО** или **нечем мерить**, и под
провалом строка «→ что сделать». Проверяются: установка и ярлык, запуск из
Finder (node, Codex, Claude Code с PATH Finder), вход в Codex, модели речи,
микрофон, Универсальный доступ, Запись экрана, хук красных линий, MCP-сервер
рабочего стола. Окон не открывает, подписку не тратит.

Разрешения проверка знает со слов самого Rujarvis — поэтому сначала один раз
открыть его, потом проверять. «Нечем мерить» у Claude Code при одном Codex —
нормально.

Проверить заодно разговор через Codex — это **один ход по подписке**:

```bash
pnpm jarvis:preflight -- --with-agent
```

Пишет `command not found: pnpm` — Homebrew не в PATH этого окна: строка
`eval …` из раздела 1, и повторить команду проверки.

## 4. Что сказать первым

По одной фразе, после каждой — дождаться ответа.

1. «**Джарвис**» — отзовётся.
2. «**Джарвис, открой калькулятор**», потом «**закрой калькулятор**» —
   прямые команды, без агента: так видно, что слух и руки на месте.
3. «**Стоп**» посреди ответа — должен замолчать сразу. Так же «тишина»,
   «пауза», «продолжай».
4. «**Джарвис, что ты умеешь**».
5. «**Джарвис, какие окна сейчас открыты**» — это уже через Codex: ответ
   дольше, секунд десять–двадцать.

Горячая клавиша «нажми и говори» — **Control+Пробел**. Если на маке этим
сочетанием переключается раскладка, зовите голосом: это известный вопрос,
решение за владельцем.

## 5. Если молчит

Журнал:

```bash
tail -60 ~/Library/Application\ Support/Rujarvis/logs/jarvis.log
```

- нет строк `услышал: …` на ваши фразы — не доходит звук: микрофон в
  Системных настройках, значок Rujarvis в строке меню → «Включить микрофон»;
- `услышал:` есть, ответа нет — смотреть строки ниже: там причина
  (вход в Codex, отказ агента, разрешение);
- после правки разрешений — перезапуск Rujarvis и снова `pnpm jarvis:preflight`.

Прислать владельцу: вывод `pnpm jarvis:preflight` и эти 60 строк журнала.
