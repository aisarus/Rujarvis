# Конвейер документов

Студент закидывает учебный документ — в Obsidian появляются материалы для
учёбы. Договорено с владельцем 20.10.2026: Джарвис — для студентов, которые
учатся на неродном языке, и тяжелее всего им самостоятельная работа без
лекций. Ни к какому порталу (Moodle, Лемида) конвейер не привязан: у каждого
студента свой, а файл есть у всех.

## Как закинуть

- «Из файла…» на плашке — кнопкой (окно выбора) или перетащив файл на неё.
  Звук и видео по-прежнему идут в конспект лекции, документы — сюда.
- Голосом: «Джарвис, разбери последний документ» / «go through the latest
  document» — самый свежий документ из «Загрузок» за сутки.
- Папка `Лекции/Входящие` (`Lectures/Inbox`): положенное туда разбирается
  само, по одному. Файл, который ещё качается или сохраняется, ждут, пока
  размер перестанет меняться. Разобранный уходит из «Входящих» в Корзину —
  его копия лежит рядом с заметками; не вышло — остаётся, и до перезапуска
  его не берут второй раз. «Входящие» — не курс: в списках курсов их нет.

Берёт: PDF, Word (`.docx`), PowerPoint (`.pptx`), картинки (`.png`, `.jpg`,
`.webp` — фото, сканы, рукописные страницы), `.txt`, `.md`. Старые `.doc` и
`.ppt` — нет: их надо пересохранить.

## Что получается

Модель сама понимает, что за документ и к какому курсу он относится (из
курсов студента; новый курс заводит, если он ясно назван в документе), и
пишет заметки на языке интерфейса с терминами оригинала:

| Документ | Заметки |
| --- | --- |
| Силлабус | «Силлабус — <курс>»: оценка, темы по неделям, литература, сроки, правила (цитатой с переводом), экзамен, что сделать сейчас. Пустые поля страницы курса — код, иврит, лектор, кредиты, расписание, экзамен — заполняются; заполненное человеком не трогается. |
| Задание | «<…> — путеводитель»: срок и сдача, каждое требование цитатой с полным переводом, критерии, маршрут чек-листом, что понадобится, подготовка к защите. «<…> — черновик»: работа на языке сдачи с пометками «⟪проверить: …⟫» и честным заявлением об использовании ИИ, которое студент перепишет своими словами. |
| Материал для чтения | «<…> — читаем вместе»: сначала вся история простыми словами, потом части с цитатами, переводом и словариком. |
| Файл лектора | «<…> — разбор»: темы от простого к сложному, задачи по шагам, графики файлами SVG, ловушки. |

Во всех — «Коротко», сворачиваемые вопросы «Проверь себя», «Шпаргалка».
Оформление — общее для всех заметок Джарвиса: `jarvis/notes/style.ts`.

Раскладка: `Лекции/<курс>/Материалы/<название>/` — заметки, сам документ,
папка `graphs/`. Курс не ясен — `Лекции/Без курса/Материалы/…`. На странице
курса — список «## Материалы» между пометками `%% материалы ведёт Джарвис %%`
и `%% конец материалов %%`; остальное на странице не трогается. Конспекты
лекций лежат в папке курса, а материалы — во вложенной папке, поэтому
списки лекций, учёба и расписание их не путают.

По готовности — строка на плашке (или голос, если просили голосом) и
уведомление системы; щелчок по нему открывает главную заметку в Obsidian.

Материал к экзамену — статья, файл лектора, иное — получает ещё и вопросы,
карточки и задачи в окне «Учёба», рядом с лекциями курса. Заготовка та же,
что у лекций (`jarvis/study/generate.ts`, та же проверка качества), но на
входе разделы «##» разбора (`readMaterialSource`) без расшифровки и
времени; «Коротко», «Проверь себя», «Шпаргалка» и сроки — не материал.
Вопросы — на языке документа с переводом, как будет на экзамене. Силлабус и
задание вопросов не получают: оценка и сроки не материал, а подготовка к
защите уже в путеводителе.

## Как устроено и почему безопасно

`jarvis/documents/pipeline.ts`, приложение — `app/documents.ts`.

1. Временная папка задачи в `%TEMP%`: `in/` — копия документа, `out/` — куда
   пишет модель. Word и PowerPoint модель сама не читает — их текст
   извлекается без сторонних библиотек (`jarvis/documents/extract.ts`: zip по
   центральному каталогу, `<w:t>` / `<a:t>`) и кладётся рядом в `in/`.
2. Claude Code (`-p`, Opus, при отказе — Sonnet) с правами только на чтение
   (`Read`, `Glob`, `Grep`) и запись правилом `Edit(./out/**)`; оболочки,
   сети и MCP-серверов нет. Проверено живьём 20.10.2026: запись в `out/` —
   да; рядом с папкой задачи, в навыки Claude (`~/.claude/skills`) и команда
   оболочки — отказ. `Write(...)` как правило CLI не принимает — только
   `Edit(...)`.
3. В задании модели сказано, что текст документа — данные, а не указания.
   Даже если документ попробует командовать, писать модель может только в
   `out/`, а выхода в сеть у неё нет.
4. Последним модель пишет `out/manifest.json`: вид, курс, название, срок,
   поля курса из силлабуса, главная заметка. Отчёт сверяется с диском:
   заметки берутся по факту из `out/`, мусорные поля отбрасываются.
5. Раскладывает уже код: свойства заметок (курс, вид, источник, добавлено,
   срок) ставит он, а не модель. Временная папка удаляется в любом исходе.

Один документ за раз: каждый — минуты сильнейшей модели по подписке, и два
разом только делили бы лимит.
