## 1. Что это сейчас

Rujarvis — самостоятельное Electron-приложение в трее для Windows 10/11, на
русском и английском. Простое делает само и без модели (прямые команды),
сложное отдаёт Claude Code (или Codex) на подписке пользователя — или Claude
Code, направленному на свой сервер модели. Перед деньгами, сообщениям людям,
системными файлами и опасными командами спрашивает голосом.

От Interpreter Workstation отделён полностью: его код удалён (история в git),
NOTICE сохраняет атрибуцию.

## 4. Что НЕ проверено — главная работа

Ничего из этого не запускалось ни разу. Каждый пункт — на **чистой Windows 10
и 11** (виртуалка), потом на настоящей машине с микрофоном.

1. **Установка одной строкой от начала до конца**
   (`irm …/install.ps1 | iex`). Git и Node через winget, pnpm через corepack,
   сборка, `jarvis:setup` (скачивание моделей), cua-driver, ярлык в «Пуске»,
   `-Autostart`, `-Language en`, повторный запуск (обновление),
   `Move-LegacyData`. Пути с кириллицей и пробелами в имени пользователя.
2. **Голос живьём**: микрофон, «Джарвис», минута без имени, `Ctrl+Space`,
   `Ctrl+M`, «стоп» во время речи Джарвиса и во время работы агента, «тишина»,
   шумная комната, разные модели Whisper.
3. **Прямые команды на Windows**: драйвер PowerShell (мышь, клавиатура, окна),
   запуск и закрытие программ через «Пуск» / `tasklist` / `taskkill`, клик по
   названию, сетка, диктовка с правкой, звук, вкладки браузера. Полный список —
   «что ты умеешь» на обоих языках.
4. **Красные линии на Windows**: хук запускается через `node` из PATH —
   проверить, что он находится после установки через winget; вопрос голосом,
   ответ «да/нет/молчание»; `git push`, покупка в браузере, отправка сообщения.
5. **Агент на Windows**: реальная задача Claude Code с инструментами рабочего
   стола, файлы в «Джарвис» по разделам, уборка корня, «покажи файл».
6. **cua-driver** (`window_*`): поднимается ли, отвечает ли на протокол
   `cuaProtocol.ts` версии 0.28.2.
7. **Английский режим целиком** — тот же прогон на английском.
8. **Своя модель** на настоящей Ollama / LM Studio / llama.cpp: кнопка
   «Проверить и включить», агентская задача, красные линии.
9. **Blender** живьём: `blender_live_start`, правки «сделай её синей» и т.п.
10. **Монтаж** на Windows с настоящими записями OBS (шрифт Segoe UI, ffmpeg
    из winget).

Вывод каждого пункта — три ответа: прошло, не прошло (с логом
`%LOCALAPPDATA%\Rujarvis\logs\jarvis.log`), нечем проверить.

## 6. Продуктовые решения, которые остаются за владельцем

- **Доступ из России.** Claude Code / Codex официально недоступны; своя модель
  (#13) — только для мощных машин. Ирина решает это через посредника с ключом;
  у нас правило «без ключей» — менять ли его.
- **Подпись кода.** Приложение собирается из исходников на машине
  пользователя, поэтому SmartScreen не мешает, но `irm | iex` требует доверия.
  Нужен ли подписанный инсталлятор.
- **Private vulnerability reporting** на GitHub не включён (на него ссылается
  `SECURITY.md`): Settings → Security.

## 8. Как работать с репозиторием

```bash
pnpm install
pnpm typecheck && pnpm test && pnpm build
pnpm jarvis:roundtrip -- --en        # голос на настоящих моделях
pwsh -NoProfile -File scripts/check-install-script.ps1
```

- Каждый коммит с `Signed-off-by` (`git commit -s`) — CI проверяет DCO.
- Изменения — через PR в `main`; CI гоняет Windows и Linux.
- Всё, что пересекает границу процесса (CLI, MCP, хук, модели речи), —
  проверять на настоящем, а не только на заглушке; писать, что не проверено.
- Грабли прошлой сессии: `fs.cpSync` на Windows падает на кириллических путях
  (сборка использует свою копию); `pkill -f` в оболочке убивает сам себя;
  `claude --allowedTools` вариативный — промпт идёт через stdin.
