# Учёба по конспектам

Окно «Учёба»: что повторить сегодня, курсы с темами, квиз, карточки,
тренировка экзамена, задачи. Читать конспект — в Obsidian; окно — чтобы
проверить себя и не забыть.

Открывается пунктом «Учёба» в трее, кнопкой «Учёба» на плашке и голосом:
«Джарвис, учёба», «открой учёбу» («open study»).

## Как это устроено

```
лекция легла в курс (finalizeLecture)
  └─ заготовка в фоне (jarvis/study/prepare.ts): Claude Code по подписке, по
     нескольку разделов за вызов → проверка качества → банк лекции
        data\study\<курс>\<лекция>.json

окно (app/studyWindow.ts + ui/study.html) ↔ служба (jarvis/study/service.ts)
  «Сегодня», курсы, квиз, карточки, экзамен, задачи
  прогресс → data\study\<курс>\progress.json
```

- **Банк лекции** — вопросы, карточки и задачи к каждому разделу конспекта
  (раздел = тема). Готовится один раз, поэтому окно открывается сразу, а
  модель зовётся только проверить открытый ответ.
- **Что уже записано раньше** — `pnpm jarvis:study-prepare` (все лекции без
  банка; `--again` — заново). В окне курса у лекции без банка есть кнопка
  «Заготовить».
- **Курсы, расписание, экзамен** — со страниц курсов в хранилище
  (`Лекции/<курс>/<курс>.md`, свойства `код`, `иврит`, `кредиты`, `лектор`,
  `расписание: 'вт 10:00-13:00'`, `экзамен: 2027-02-10`). Расписание нужно и
  кнопке конспекта: с первой пары она пишет лекцию в нужный курс.

Формат вопроса, правила доверия и шкала знания взяты из Lamdan
(github.com/aisarus/syllabus-to-os) и переписаны под Claude по подписке.

## Вопрос

Четыре варианта, один верный — пометкой `"correct": true` у самого варианта,
а не номером: первая заготовка (30.09.2026) шла с номером, модель считала его
с единицы, код — с нуля, и «верно» в разборе стояло у одного варианта, а
засчитывался другой. У каждого варианта — почему он верен или неверен; разбор,
подсказка для памяти, эталон для открытого ответа, место в лекции (минута).

Лекция на другом языке (иврит) — вопрос и варианты на её языке, как на
экзамене, с переводом; перевод прячется переключателем. Разбор — на языке
интерфейса.

**Проверка качества** (`jarvis/study/quality.ts`) выбрасывает, а не
чинит: не четыре варианта, повторы, пустое, не один верный, нет перевода, нет
разбора, повтор вопроса, **разбор спорит с пометкой** («Верно…» у ловушки).
Место в лекции вне своего раздела — прижимается к началу раздела. Всё
выброшенное — в `warnings` банка.

## Квиз

Выбор варианта проверяется сразу, без модели: окно получает варианты
перемешанными и без верного ответа, верный остаётся в службе до ответа. После
ответа — разбор каждого варианта, подсказка и «▶ лекция 2, 14:05»: звук
лекции с этой минуты (с запасом в три секунды) прямо в окне.

Ответить своими словами — текстом или диктовкой Джарвиса («Джарвис,
диктуй»). Проверяет Claude Code — только по эталону и тексту лекции
(`openAnswer.ts`): «верно», «почти», «неверно» и почему. Холодный вызов —
около 15 секунд.

Ошибка — сама карточка. Повторная ошибка по тому же вопросу — карточка сейчас
же снова к повторению.

## Шкала знания

Не проценты, а пять состояний (`jarvis/study/knowledge.ts`):

| Состояние | Когда |
| --- | --- |
| не встречал | к теме нет ни вопросов, ни карточек |
| пройдено | материал есть, проверки не было |
| шатко | что-то отвечено, но мало, давно или однообразно |
| слабо | две ошибки и больше, и последняя — ошибка (или ошибок половина) |
| знаю | ≥4 верных, из них ≥2 проверены машиной, за ≥2 дня, ≥2 способами (квиз и карточки), ошибок ≤⅓, последняя — не ошибка, последний верный — не старше 21 дня |

Самопроверка задач («решил») — со слов человека, «знаю» одна не даёт. Риск
забыть — по времени с последнего верного ответа: неделя — низкий, три
недели — средний, дальше — высокий; такие темы «Сегодня» зовёт освежить.

## Карточки

Одна большая, переворот пробелом или щелчком, «1 · Ещё раз» и «2 · Знаю».
«Ещё раз» — через десять минут, «Знаю» — через день, потом через три, дальше
каждый раз в два с половиной раза дольше. Карточки — из «Понятий» лекции и
из ошибок.

## Экзамен

Вопросы по всему курсу, слабые и шаткие темы — первыми, замораживаются на
старте. Таймер; разбор — только после сдачи; время вышло — сдаётся само.
Без ответа — ни удача, ни ошибка: не отвеченное не выдумывается.

## Задачи

Только если в лекции были расчёты, формулы или код: условие, подсказка,
решение по шагам, ответ. «Решил» / «Не вышло» — отметка человека.

## «Сегодня»

Пары дня по расписанию; карточки к повторению; квиз по лекции, где ещё не
проверял себя; слабые места; темы, которые пора освежить; экзамен ближе
тридцати дней — тренировка; нерешённые задачи.

## Проверки

```bash
pnpm jarvis:study-prepare                 # заготовить банки настоящим Claude Code
pnpm jarvis:study-window-check            # окно настоящим Электроном, скрытым
```

`study-window-check` — страница, мост и служба вместе, на копии банков
(прогресс не трогает), окно не показывается и фокус не берёт: «Сегодня»
нарисовано, после ответа — разбор всех четырёх вариантов, звук лекции
открывается из файла при защите страницы. Прогон 30.09.2026 — прошло.

Прогон заготовки 30.09.2026 на лекции «От Большого взрыва к истории культур»
(2 мин, иврит): 5 вопросов, 9 карточек за 72 с, верные варианты на разных
местах, ни одного выброшенного.

## Что не сделано

- План до экзамена по дням (из Lamdan) — «Сегодня» пока знает только, сколько
  дней до экзамена, и тренировку.
- PDF курса — вопросы и задачи пока только из лекций.
- Микрофон прямо в окне — ответ голосом идёт диктовкой Джарвиса.
- Окно в приложении у живого человека — кнопка на плашке, трей, голос — не
  нажималось: без разрешения владельца экран не трогается.
