# Конспект лекции

«Джарвис, конспектируй лекцию по матанализу» («Jarvis, take lecture notes for
calculus») — и Джарвис слушает аудиторию и ведёт конспект прямо во время
лекции. «Джарвис, закончи конспект» («Jarvis, stop lecture notes») — дописывает
итог и закрывает запись.

Конспект пишется на языке интерфейса — русском или английском. Лекция по
умолчанию на том же языке; другой язык лекции — настройка (см. ниже).

**Кнопка под плашкой** — «● Конспект» / «■ Закончить конспект»: в
аудитории вслух не покомандуешь. Нажатие не забирает фокус, а Джарвис
отвечает строкой на плашке, а не голосом.

**Голос во время лекции** слушает только «стоп», «тишина» и прямые команды:
«Джарвис, закончи конспект» одной фразой или «Джарвис» — «Слушаю» —
«закончи конспект». Каша, которую русский слух слышит в чужой речи, в
разговор не уходит (`jarvis/lecture/voiceGate.ts`): живой прогон 29.09.2026
принял «Джаред Даймонд» за «Джарвис».

## Что получается

В открытом хранилище Obsidian, в папке `Лекции` (`Lectures` у английского
интерфейса); открытого нет — в последнем открывавшемся. Берутся только
хранилища, которые есть на диске: Obsidian помнит и удалённые. Obsidian не
найден — в папке результатов Джарвиса:

| Файл | Что там |
| --- | --- |
| `2026-09-29 матанализу.md` | Конспект: разделы по мере лекции, в конце — итог сверху |
| `2026-09-29 матанализу — расшифровка.md` | Дословно, с метками времени `**[12:40]**` |
| `2026-09-29 матанализу.wav` | Звук лекции, 16 кГц моно |

Предмет в имени — как сказан («по матанализу» → «матанализу»). Без предмета —
`2026-09-29 1005 Лекция` (`Lecture`).

Заметка открывается в Obsidian сразу при старте, и видно, как она растёт:
расшифровка — кусок за куском, раздел конспекта — раз в пять минут, когда
набралось хотя бы 120 слов. В конце сверху встают **Кратко**, **Понятия** и
**Вопросы к экзамену** (**Summary**, **Concepts**, **Exam questions**).

## Как устроено

```
микрофон (режим лекции) → куски ≤28 с
  ├─ модель для лекций (whisper.cpp, large-v3-turbo, порт 8179) → расшифровка
  │     └─ раз в 5 минут → Claude Code (Sonnet, по подписке) → раздел конспекта
  └─ слух команд (small, порт 8178) → только «Джарвис, …», «стоп», «тишина»
```

- **Режим лекции на странице микрофона** (`app/audioBridgePage.ts`): порог речи
  ×0,4 — лектор дальше, чем человек у ноутбука; запись до 28 секунд вместо 15 —
  мысль лектора не режется на полуслове.
- **Мост** (`app/voiceBridge.ts`, `app/lectureMode.ts`): каждый кусок уходит в
  конспект раньше слуха команд — упади общий сервер, лекция всё равно пишется.
  Дальше в разговор проходит только обращённое к Джарвису: имя, «стоп»,
  «тишина». Остальное из аудитории — не команды.
- **Сессия** (`jarvis/lecture/session.ts`): две очереди. Расшифровка
  дописывается сразу, разделы — своей очередью: модель думает десятки секунд, и
  расшифровка её не ждёт. Раздел не собрался (лимит подписки, сеть) — в конспекте
  пометка, текст остаётся в расшифровке. Кусок без содержания лекции модель
  пропускает. Метка времени — начало куска.
- **Модель для разделов** (`jarvis/lecture/summarize.ts`): `claude -p` с
  промптом через stdin, без MCP-серверов, в нейтральной папке, окружение задач
  (`agentEnv`) — только подписка, ключи API вычищены. Sonnet: 15–20 вызовов за
  полуторачасовую лекцию бережут лимиты.

Сервер модели для лекций поднимается при «конспектируй» (несколько секунд на
видеокарте) и гасится по своему pid, когда итог дописан. Пока он поднимается,
куски ждут в очереди. Итог — минута-другая модели, и мост его не ждёт: реплики
разбираются по одной, и «стоп» не должен стоять за моделью. Джарвис говорит
«дописываю итог», а когда готово — «конспект готов». Новая лекция, пока
дописывается прошлая, не начинается: сервер прошлой занимает тот же порт.
Модели для лекций нет — слушает общий сервер (small) с языком лекции: хуже, и
Джарвис это говорит.

Закрыли Джарвиса посреди лекции — расшифровка и звук остаются на диске (звук
целым: заголовок WAV дописывается при закрытии), а разделов и итога нет: на
них нужна минута модели. Дописать по сохранённой расшифровке:

```bash
pnpm jarvis:lecture-finish
```

Без аргумента берётся последняя недописанная лекция в папке лекций.
Организационное, важное студенту (формат экзамена, литература, часы приёма),
идёт коротким разделом «Организационное», а не пропускается.

## Установка

Нужно распознавание на видеокарте (`pnpm jarvis:gpu-stt`), затем — по желанию,
для точности — модель для лекций:

```bash
pnpm jarvis:lecture-model
```

large-v3-turbo в q5_0 из репозитория whisper.cpp: 574 МБ, около
полугигабайта видеопамяти, sha256 сверяется. Без неё конспект пишется, но
слушает small — модель, подобранная под короткие команды.

## Другой язык лекции

В `data/settings.json` — `"lectureLanguage"`: код языка, как его понимает
Whisper (`"de"`, `"fr"`, `"he"`…). Пусто — язык интерфейса. Конспект остаётся
на языке интерфейса, а термины в нём идут в скобках так, как их сказал лектор.

Для языка со своей дообученной моделью `pnpm jarvis:lecture-model` ставит её
вместо общей (таблица `LECTURE_MODELS` в `jarvis/voice/gpuWhisper.ts`). Сейчас
такая одна — ivrit.ai для иврита: выложена несжатой (1,6 ГБ) и сжимается у
себя до q5_0 утилитой `whisper-quantize`. На записях университетских лекций
на иврите она ошибается в 14% слов против 35% у small (замер 29.09.2026, 40
фраз из открытых наборов Campus и Coursera).

## Проверка

```bash
pnpm jarvis:lecture-check -- лекция.wav
```

Свой сервер модели для лекций на свободном порту, запись режется на куски по
20 секунд, разделы и итог пишет настоящий Claude Code. Язык — из настроек или
`--language=xx`. Результат — в папке данных Джарвиса (`data\lecture-check\`),
не в хранилище Obsidian. Прошло — есть расшифровка, раздел и итог,
распознавание быстрее реального времени.

Без записи сервер слушает фразу голоса Piper: на русском и английском это
проверка слуха, на другом языке — только того, что сервер отвечает. Про сам
конспект проверка без записи честно говорит «нечем мерить».

Прогон 29.09.2026 на 250 секундах записанной лекции: три раздела и итог через
Claude Code за 75 секунд после конца записи, распознавание — 0,09 реального
времени. Он же нашёл две ошибки клиента распознавания, обе исправлены
(`cleanWhisperText` в `app/gpuTranscriber.ts`): сегмент сервера мог кончиться
посреди слова, и слово рвалось переводом строки; модель ставила в начало
сегментов невидимые знаки направления письма.

## Что знать

- Расшифровка лекции уходит в Claude Code по подписке — так же, как любая
  задача. Звук никуда не уходит.
- В журнал Джарвиса пишутся только счёт и события («кусок 12:40: 38 слов»), не
  текст лекции.
- «Немой режим» (`Ctrl+M`) выключает микрофон целиком — и конспект тоже.
- Записывать лекцию — по правилам вашего университета и с согласия лектора.
