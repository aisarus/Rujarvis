# Конспект лекции

«Джарвис, конспектируй лекцию по матанализу» — и Джарвис слушает аудиторию,
распознаёт иврит и ведёт конспект на русском прямо во время лекции. «Джарвис,
закончи конспект» — дописывает итог и закрывает запись.

Решения владельца (29.09.2026): лекции на иврите, в аудитории, микрофон
ноутбука; конспект на русском с терминами на иврите в скобках; рядом —
дословная расшифровка на иврите и звук.

## Что получается

В открытом хранилище Obsidian, в папке `Лекции` (Obsidian не найден — в папке
результатов Джарвиса, тоже в `Лекции`):

| Файл | Что там |
| --- | --- |
| `2026-09-29 матанализу.md` | Конспект: разделы по мере лекции, в конце — итог сверху |
| `2026-09-29 матанализу — расшифровка.md` | Дословно, на иврите, с метками времени `**[12:40]**` |
| `2026-09-29 матанализу.wav` | Звук лекции, 16 кГц моно |

Предмет в имени — как сказан («по матанализу» → «матанализу»). Без предмета —
`2026-09-29 1005 Лекция`.

Заметка открывается в Obsidian сразу при старте, и видно, как она растёт:
расшифровка — кусок за куском, раздел конспекта — раз в пять минут, когда
набралось хотя бы 120 слов. В конце сверху встают **Кратко**, **Понятия** (термин
по-русски и на иврите) и **Вопросы к экзамену**.

## Как устроено

```
микрофон (режим лекции) → куски ≤28 с
  ├─ сервер иврита (whisper.cpp, ivrit.ai large-v3-turbo, порт 8179) → расшифровка
  │     └─ раз в 5 минут → Claude Code (Sonnet, по подписке) → раздел конспекта
  └─ русский слух (small, порт 8178) → только «Джарвис, …», «стоп», «тишина»
```

- **Режим лекции на странице микрофона** (`app/audioBridgePage.ts`): порог речи
  ×0,4 — лектор дальше, чем человек у ноутбука; запись до 28 секунд вместо 15 —
  мысль лектора не режется на полуслове.
- **Мост** (`app/voiceBridge.ts`, `app/lectureMode.ts`): каждый кусок уходит в
  конспект раньше русского слуха — упади общий сервер, лекция всё равно пишется.
  Дальше в разговор проходит только обращённое к Джарвису: имя, «стоп»,
  «тишина». Остальное из аудитории — не команды.
- **Сессия** (`jarvis/lecture/session.ts`): две очереди. Расшифровка
  дописывается сразу, разделы — своей очередью: модель думает десятки секунд, и
  расшифровка её не ждёт. Раздел не собрался (лимит подписки, сеть) — в конспекте
  пометка, текст остаётся в расшифровке. Кусок без содержания лекции модель
  пропускает.
- **Модель для разделов** (`jarvis/lecture/summarize.ts`): `claude -p` с
  промптом через stdin, без MCP-серверов, в нейтральной папке, окружение задач
  (`agentEnv`) — только подписка, ключи API вычищены. Sonnet: 15–20 вызовов за
  полуторачасовую лекцию бережут лимиты.

Сервер иврита поднимается при «конспектируй» (несколько секунд на CUDA) и
гасится по своему pid при «закончи». Пока он поднимается, куски ждут в очереди.
Модели иврита нет — слушает общий сервер с языком «иврит»: хуже, и Джарвис это
говорит.

Закрыли Джарвиса посреди лекции — записанное остаётся на диске как есть, итога
нет: на него нужна минута модели.

## Установка

Нужно распознавание на видеокарте (`pnpm jarvis:gpu-stt`), затем:

```bash
pnpm jarvis:lecture-model
```

Скачивает ivrit.ai whisper-large-v3-turbo (1,6 ГБ, Apache-2.0), сверяет sha256,
сжимает у себя до q5_0 (574 МБ, около полугигабайта видеопамяти) и стирает
исходник. Сжимает `whisper-quantize` — из той же сборки на Windows, из Homebrew
на маке. Не нашлось утилиты — модель ставится несжатой
(`ggml-ivrit-turbo-f16.bin`, 1,6 ГБ): работает так же, памяти берёт больше.

## Проверка

```bash
pnpm jarvis:lecture-check -- лекция.wav
```

Свой сервер иврита на свободном порту, запись режется на куски по 20 секунд,
разделы и итог пишет настоящий Claude Code. Результат — в папке данных
Джарвиса (`data\lecture-check\`), не в хранилище Obsidian. Прошло — есть
расшифровка, раздел и итог, распознавание быстрее реального времени.

Без записи проверяется только, что сервер иврита поднимается и отвечает, и
проверка честно говорит «нечем мерить» про качество иврита. Замер на машине
владельца 29.09.2026: сервер за 3 с на CUDA, фраза — 0,7 с. Качество на
настоящей лекции ещё не мерено: нужна запись на иврите.

## Что знать

- Расшифровка лекции уходит в Claude Code по подписке — так же, как любая
  задача. Звук никуда не уходит.
- В журнал Джарвиса пишутся только счёт и события («кусок 12:40: 38 слов»), не
  текст лекции.
- «Немой режим» (`Ctrl+M`) выключает микрофон целиком — и конспект тоже.
- Записывать лекцию — по правилам вашего университета и с согласия лектора.
