# Синхронизация с upstream — больше не нужна

Rujarvis начинался как форк Interpreter Workstation и какое-то время держал
правки upstream точечными, чтобы забирать его изменения. С версии 0.3 он —
самостоятельное приложение: ни один файл в `app/` и `jarvis/` не импортирует
код Workstation, `package.json` не зависит от его пакетов, сборка и CI его не
касаются.

Происхождение сохранено в истории git и в [NOTICE](../../NOTICE). Если нужно
что-то из Workstation, берите это как любой код под Apache 2.0: копией с
указанием источника, а не слиянием веток.
