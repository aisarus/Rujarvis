# Ассистент в Доте, шаги 1–3 — план работ

> **Для агентов:** ОБЯЗАТЕЛЬНЫЙ ПОДНАВЫК: используй superpowers:subagent-driven-development (рекомендуется) или superpowers:executing-plans, чтобы вести план задача за задачей. Шаги отмечаются флажками (`- [ ]`).

**Цель:** приёмник GSI, свёрнутое состояние с лагерями и пороги опасности и золота — всё, что считается без зрения и без модели.

**Устройство:** пакет GSI разбирается в плоский типизированный снимок; снимки сворачиваются в состояние; пороги читают состояние и отвечают трёхзначными воротами. Ни одного обращения к модели, ни одного сетевого запроса.

**Чем пишем:** TypeScript, vitest, встроенный `node:http`. Никаких новых зависимостей.

**Замысел:** [docs/superpowers/specs/2026-09-21-ассистент-в-доте-design.md](../specs/2026-09-21-ассистент-в-доте-design.md)

## Общие ограничения

- Имена экспортов латиницей, комментарии и названия тестов по-русски — как в `jarvis/measure/gate.ts`.
- Тесты лежат рядом с модулем и называются `<модуль>.vitest.test.ts`; их подхватывает `jarvis/**/*.vitest.test.ts` в `vitest.config.ts`.
- Прогон одного файла: `pnpm exec vitest run --config vitest.config.ts jarvis/dota/<файл>.vitest.test.ts`
- Полный набор перед коммитом: `pnpm run typecheck && pnpm exec vitest run --config vitest.config.ts jarvis/`
- Новых зависимостей не добавлять.
- Пороги, не подтверждённые числами на записи, в работу не идут.
- Файлы в репозитории с `CRLF`; правки это учитывают.
- **Запись живой игры в репозиторий не кладём.** Она лежит в `C:\Users\ariel\Desktop\Джарвис\разведка-доты\запись-2026-09-21-1255` (`gsi.jsonl`, 495 МБ). В репозиторий идут только два настоящих пакета как образцы.

Создать `jarvis/dota/packet.ts`:

```ts
/**
 * Разбор пакета Game State Integration в плоский снимок.
 *
 * ## Почему не отдаём сырой JSON дальше
 *
 * Сырой пакет — это до 209 безымянных объектов в `minimap`, разложенных по
 * ключам `o0`…`o208`, и полтора десятка блоков, четыре из которых всегда
 * пусты. Каждый, кто захочет узнать «кто из врагов рядом», иначе напишет свой
 * фильтр по `image === 'minimap_enemyicon'` — и однажды напишет его неверно.
 *
 * Так и вышло при разведке: фильтр по `herocircle` пропустил всех врагов,
 * потому что враги приходят другой иконкой. Один разбор в одном месте.
 *
 * ## Что считается союзником
 *
 * Только герой с именем. `minimap_herocircle` приходит и на иллюзии Лансера, и
 * на скелетов Рейдж Кинга — их за игру набралось 389 738 штук. Считать их
 * друзьями значит получить «союзник рядом» там, где ты один.
 */

/** Объект на миникарте: герой, крип, вард, здание. */
export interface MapObject {
  x: number;
  y: number;
  /** Картинка Доты: `minimap_enemyicon`, `minimap_herocircle`, … */
  icon: string;
  /** 2 — radiant, 3 — dire, 4 — нейтралы, 5 — ничьи. */
  team: number;
  /** Имя героя, если объект — герой. */
  hero?: string;
  yaw: number;
  /** Дальность обзора этого объекта. */
  vision: number;
}

export interface SelfHero {
  hero: string;
  level: number;
  alive: boolean;
  /** Здоровье в процентах, 0..100. */
  hp: number;
  x: number;
  y: number;
  buybackCost: number;
  buybackCooldown: number;
}

export interface DotaEvent {
  kind: string;
  gameTime: number;
  /** Разобранное содержимое `data`, если оно было строкой с JSON. */
  data?: Record<string, unknown>;
}

export interface DotaPacket {
  /** Настенное время приёма, миллисекунды. */
  at: number;
  clock: number | null;
  state: string | null;
  matchId: string | null;
  self: SelfHero | null;
  gold: number | null;
  lastHits: number | null;
  deaths: number | null;
  enemies: MapObject[];
  allies: MapObject[];
  neutrals: MapObject[];
  events: DotaEvent[];
}

function число(значение: unknown): number | null {
  return typeof значение === 'number' && Number.isFinite(значение) ? значение : null;
}

function объект(сырой: Record<string, unknown>): MapObject | null {
  const x = число(сырой.xpos);
  const y = число(сырой.ypos);
  if (x === null || y === null || typeof сырой.image !== 'string') return null;
  const имя = typeof сырой.name === 'string' && сырой.name.startsWith('npc_dota_hero_')
    ? сырой.name
    : undefined;
  return {
    x,
    y,
    icon: сырой.image,
    team: число(сырой.team) ?? 0,
    hero: имя,
    yaw: число(сырой.yaw) ?? 0,
    vision: число(сырой.visionrange) ?? 0,
  };
}

function события(сырые: unknown): DotaEvent[] {
  if (!Array.isArray(сырые)) return [];
  const итог: DotaEvent[] = [];
  for (const е of сырые) {
    if (!е || typeof е !== 'object') continue;
    const запись = е as Record<string, unknown>;
    const вид = typeof запись.event_type === 'string' ? запись.event_type : null;
    if (!вид) continue;
    let данные: Record<string, unknown> | undefined;
    if (typeof запись.data === 'string') {
      // Дота кладёт сюда строку с JSON: тип чат-сообщения, слоты, время.
      try { данные = JSON.parse(запись.data) as Record<string, unknown>; } catch { данные = undefined; }
    }
    итог.push({ kind: вид, gameTime: число(запись.game_time) ?? 0, data: данные });
  }
  return итог;
}

/**
 * Разобрать сырой пакет. Возвращает `null`, если это не пакет Доты, —
 * бросать нельзя: приёмник не должен падать от мусора на порту.
 */
export function readPacket(сырой: unknown, at: number = Date.now()): DotaPacket | null {
  if (!сырой || typeof сырой !== 'object') return null;
  const пакет = сырой as Record<string, unknown>;

  const геройСырой = (пакет.hero ?? null) as Record<string, unknown> | null;
  const игрок = (пакет.player ?? null) as Record<string, unknown> | null;
  const карта = (пакет.map ?? null) as Record<string, unknown> | null;

  let свой: SelfHero | null = null;
  if (геройСырой && typeof геройСырой.name === 'string') {
    const x = число(геройСырой.xpos);
    const y = число(геройСырой.ypos);
    if (x === null || y === null) return null;
    свой = {
      hero: геройСырой.name,
      level: число(геройСырой.level) ?? 0,
      alive: геройСырой.alive !== false,
      hp: число(геройСырой.health_percent) ?? 0,
      x,
      y,
      buybackCost: число(геройСырой.buyback_cost) ?? 0,
      buybackCooldown: число(геройСырой.buyback_cooldown) ?? 0,
    };
  }

  const враги: MapObject[] = [];
  const союзники: MapObject[] = [];
  const нейтралы: MapObject[] = [];
  const миникарта = (пакет.minimap ?? null) as Record<string, unknown> | null;
  if (миникарта) {
    for (const сырая of Object.values(миникарта)) {
      if (!сырая || typeof сырая !== 'object') continue;
      const о = объект(сырая as Record<string, unknown>);
      if (!о) continue;
      if (о.icon === 'minimap_enemyicon') враги.push(о);
      else if (о.icon === 'minimap_herocircle' && о.hero && о.hero !== свой?.hero) союзники.push(о);
      else if (о.team === 4) нейтралы.push(о);
    }
  }

  const снимок: DotaPacket = {
    at,
    clock: карта ? число(карта.clock_time) : null,
    state: карта && typeof карта.game_state === 'string' ? карта.game_state : null,
    matchId: карта && typeof карта.matchid === 'string' ? карта.matchid : null,
    self: свой,
    gold: игрок ? число(игрок.gold) : null,
    lastHits: игрок ? число(игрок.last_hits) : null,
    deaths: игрок ? число(игрок.deaths) : null,
    enemies: враги,
    allies: союзники,
    neutrals: нейтралы,
    events: события(пакет.events),
  };

  // Пакет без героя и без карты — это приветствие из меню, а не игра.
  if (!снимок.self && !снимок.clock) return null;
  return снимок;
}
```

```ts
/**
 * Приём пакетов Game State Integration.
 *
 * ## Почему свой сервер, а не готовая обвязка
 *
 * Работы здесь на тридцать строк: Дота шлёт POST с JSON на локальный адрес,
 * ответ ей безразличен. Зависимость ради этого — лишний повод сломаться.
 *
 * ## Почему обработчик обёрнут в try
 *
 * Пакеты идут по два-три в секунду и никого не ждут. Исключение в пороге,
 * если его не поймать, оборвёт приём до конца матча — и человек этого даже не
 * заметит, потому что тишина помощника выглядит в точности как «всё спокойно».
 * Это ровно тот вид поломки, на который ушёл весь день 20 сентября.
 *
 * ## Настройка со стороны игры
 *
 * Файл `gamestate_integration_jarvis.cfg` в `game/dota/cfg/gamestate_integration/`
 * и ключ запуска `-gamestateintegration`. Без ключа игра молчит и никак об
 * этом не сообщает.
 */
import { createServer, type Server } from 'node:http';

import { readPacket, type DotaPacket } from './packet';

/** Порт из конфига разведки. Занят — значит уже кто-то слушает. */
export const DEFAULT_PORT = 39847;

export interface ReceiverOptions {
  /** 0 — просить свободный у системы; так работают тесты. */
  port?: number;
  onPacket(packet: DotaPacket): void;
  /** Нечитаемое тело. Молчать о нём нельзя: это признак беды на той стороне. */
  onJunk?(raw: string): void;
}

export interface Receiver {
  port: number;
  stop(): Promise<void>;
}

export async function startReceiver(options: ReceiverOptions): Promise<Receiver> {
  const сервер: Server = createServer((запрос, ответ) => {
    let тело = '';
    запрос.on('data', (кусок) => { тело += кусок; });
    запрос.on('end', () => {
      ответ.writeHead(200, { 'Content-Type': 'text/plain' });
      ответ.end('ok');

      let сырой: unknown;
      try { сырой = JSON.parse(тело); } catch { options.onJunk?.(тело); return; }

      const пакет = readPacket(сырой);
      if (!пакет) { options.onJunk?.(тело); return; }

      try { options.onPacket(пакет); } catch (беда) {
        // Приём важнее любого одного потребителя.
        console.error('[dota] обработчик пакета бросил:', беда);
      }
    });
  });

  await new Promise<void>((готово) => {
    сервер.listen(options.port ?? DEFAULT_PORT, '127.0.0.1', готово);
  });

  const адрес = сервер.address();
  const порт = typeof адрес === 'object' && адрес ? адрес.port : (options.port ?? DEFAULT_PORT);
```

```ts
/**
 * Лагерь в трёх состояниях: жив, пуст, давно не смотрели.
 *
 * ## Почему три, а не два
 *
 * Потому что «я там никого не вижу» и «там никого нет» — разные новости, и
 * вторая следует из первой только если ты туда смотришь. Человек сформулировал
 * это сам: показывать надо те лагеря, «про которые известно».
 *
 * Оверлей, гасящий половину карты, стоит герою отойти на базу, хуже
 * отсутствующего: он выглядит осведомлённым.
 *
 * ## Как решается, смотрим ли мы
 *
 * По дальности обзора героя. Точнее было бы учитывать вардов и союзников —
 * у каждого объекта на миникарте своя `visionrange`, — но этого достаточно
 * для первого шага и не требует ни одного допущения.
 */
import type { DotaPacket } from './packet';
import { CAMP_POSITIONS, type CampPosition } from './campPositions';

/** Жив, пуст или давно не смотрели. */
export type CampState = 'alive' | 'empty' | 'stale';

export interface Camp {
  x: number;
  y: number;
  state: CampState;
  /** Когда в последний раз видели своими глазами. */
  seenAt: number | null;
}

/** Насколько близко к лагерю считается «вижу». Обзор героя — 800. */
const ВИДНО = 900;

/** Радиус, в котором нейтрал считается принадлежащим лагерю. */
const СВОЙ = 600;

/** Через сколько без взгляда состояние выцветает в «не знаю». */
const ВЫЦВЕТАЕТ = 60_000;

export function createCamps(positions: readonly CampPosition[] = CAMP_POSITIONS): Camp[] {
  return positions.map((п) => ({ x: п.x, y: п.y, state: 'stale' as CampState, seenAt: null }));
}

export function updateCamps(
  camps: readonly Camp[],
  packet: DotaPacket,
  options: { staleAfterMs?: number } = {},
): Camp[] {
  const выцветает = options.staleAfterMs ?? ВЫЦВЕТАЕТ;
  const свой = packet.self;
  if (!свой) return [...camps];

  return camps.map((лагерь) => {
    const доГероя = Math.hypot(лагерь.x - свой.x, лагерь.y - свой.y);
    if (доГероя > ВИДНО) {
      // Не смотрим. Старое знание живёт, пока не состарится.
      const прошло = лагерь.seenAt === null ? Infinity : packet.at - лагерь.seenAt;
      return прошло > выцветает ? { ...лагерь, state: 'stale' as CampState } : { ...лагерь };
    }
    const есть = packet.neutrals.some((н) => Math.hypot(н.x - лагерь.x, н.y - лагерь.y) < СВОЙ);
    return { ...лагерь, state: (есть ? 'alive' : 'empty') as CampState, seenAt: packet.at };
  });
}
```

```ts
/**
 * Свёрнутое состояние матча.
 *
 * ## Что здесь есть и чего нет
 *
 * Здесь только то, что нельзя узнать из одного пакета: с какого мига копится
 * золото, сколько раз героя поймали, что видно у лагерей. Всё, что читается
 * из последнего пакета напрямую, здесь не дублируется — иначе два источника
 * правды разойдутся.
 *
 * ## Поймали и умер — разные числа
 *
 * `caughtOut` растёт по флагу `alive`, `deaths` берётся из счётчика игры. У
 * Рейдж Кинга реинкарнация гасит флаг, не увеличивая счётчик: за матч
 * `9009407694` восемнадцать пометок обернулись восемью смертями. Для порога
 * опасности правильны именно восемнадцать — героя ловили восемнадцать раз.
 */
import { createCamps, updateCamps, type Camp } from './camps';
import type { DotaPacket } from './packet';

export interface DotaState {
  latest: DotaPacket | null;
  camps: Camp[];
  /** Миг, когда золото перешло отметку и с тех пор её не опускалось. */
  goldSince: number | null;
  /** Смерти по счётчику игры. */
  deaths: number;
  /** Сколько раз героя убили, считая реинкарнации. */
  caughtOut: number;
}

/** Отметка золота по умолчанию: замер 21.09.2026 дал две реплики за матч. */
export const GOLD_MARK = 2000;

export function createState(): DotaState {
  return { latest: null, camps: createCamps(), goldSince: null, deaths: 0, caughtOut: 0 };
}

export function applyPacket(
  state: DotaState,
  packet: DotaPacket,
  options: { goldMark?: number } = {},
): DotaState {
  const отметка = options.goldMark ?? GOLD_MARK;
  const былЖив = state.latest?.self?.alive ?? true;

  let золотоС = state.goldSince;
  if (packet.gold !== null) {
    if (packet.gold >= отметка) золотоС ??= packet.at;
    else золотоС = null;
  }

  const поймали = state.caughtOut + (былЖив && packet.self?.alive === false ? 1 : 0);

  return {
    latest: packet,
    camps: packet.self ? updateCamps(state.camps, packet) : state.camps,
    goldSince: золотоС,
    deaths: packet.deaths ?? state.deaths,
    caughtOut: поймали,
  };
}
```

```ts
/**
 * Пороги опасности и золота.
 *
 * ## Числа не придуманы
 *
 * Все они сняты с матча `9009407694` (21.09.2026, 54 минуты, 12 785 пакетов).
 * Порог «трое в 1200 либо один в 600 при здоровье ниже 40%» поймал **18 случаев
 * из 18**, когда героя убили, при **одной** ложной тревоге за игру и форе в
 * **9,1 секунды** в среднем.
 *
 * Перебиралось четыре радиуса, два количества, три близких радиуса и два порога
 * здоровья. Этот набор — лучший по тишине среди поймавших всё.
 *
 * ## Чего здесь намеренно нет
 *
 * **Минимальной длительности тревоги.** Она убрала бы единственный шум —
 * секундное мелькание троих на 38:45, — но заодно лишила бы предупреждения ту
 * смерть, где форы было 1,8 секунды. Один ложный сигнал за 54 минуты дешевле
 * одной потерянной смерти.
 *
 * **Условия «на чужой половине».** Там проходит 46% живого времени, и как
 * самостоятельное условие оно только ухудшало результат в переборе.
 *
 * **Порога простоя.** Замер: из 42 остановок дольше 15 секунд настоящими
 * потерями были 8. Отрицательный результат, записан, чтобы за него не взялись
 * снова.
 *
 * ## Почему ворота, а не булево
 *
 * Мёртвый герой и пакет без героя — это не «опасности нет», а «нечем мерить».
 * Свернуть их в спокойствие значит молчать ровно тогда, когда прибор сломан.
 */
import { cannotMeasure, failed, passed, type Gate } from '../measure/gate';
import type { DotaPacket } from './packet';
import type { DotaState } from './state';

export interface DangerRule {
  /** Радиус, в котором считаем врагов. */
  nearRadius: number;
  /** Сколько врагов в этом радиусе — уже опасность. */
  nearCount: number;
  /** Радиус «вплотную». */
  closeRadius: number;
  /** Здоровье, ниже которого хватает одного врага вплотную. */
  closeHp: number;
}

export const DEFAULT_DANGER: DangerRule = {
  nearRadius: 1200,
  nearCount: 3,
  closeRadius: 600,
  closeHp: 40,
};

const СЧЁТОМ = ['ноль', 'один', 'двое', 'трое', 'четверо', 'пятеро'];

export function judgeDanger(packet: DotaPacket, rule: DangerRule = DEFAULT_DANGER): Gate {
  const свой = packet.self;
  if (!свой) return cannotMeasure('в пакете нет своего героя');
  if (!свой.alive) return cannotMeasure('герой мёртв');

  const расстояния = packet.enemies
    .map((в) => Math.hypot(в.x - свой.x, в.y - свой.y))
    .sort((a, б) => a - б);

  const рядом = расстояния.filter((р) => р < rule.nearRadius).length;
  if (рядом >= rule.nearCount) {
    return failed(`${СЧЁТОМ[Math.min(рядом, 5)]} в ${rule.nearRadius}`);
  }

  const ближайший = расстояния[0];
  if (ближайший !== undefined && ближайший < rule.closeRadius && свой.hp < rule.closeHp) {
    return failed(`один вплотную при здоровье ${свой.hp}%`);
  }

  return passed();
}

export interface GoldRule {
  /** Сколько золота считается «лежит». */
  amount: number;
  /** Сколько оно должно пролежать, прежде чем об этом сказать. */
  heldMs: number;
}

/** Замер 21.09.2026: 2000 дольше 45 секунд — две реплики за матч. */
export const DEFAULT_GOLD: GoldRule = { amount: 2000, heldMs: 45_000 };

export function judgeGold(state: DotaState, rule: GoldRule = DEFAULT_GOLD): Gate {
  if (!state.latest) return cannotMeasure('пакетов ещё не было');
  if (state.goldSince === null) return passed();
  const лежит = state.latest.at - state.goldSince;
  return лежит >= rule.heldMs
    ? failed(`${state.latest.gold} лежит ${Math.round(лежит / 1000)} секунд`)
    : passed();
}
```

**Файлы:**

```js
/**
 * Прогон порогов по записи живой игры.
 *
 * ## Зачем отдельно от тестов
 *
 * Запись весит 495 МБ и в репозиторий не кладётся. Но без неё пороги — слова:
 * юнит-тест докажет, что «трое в радиусе» считается правильно, и ничего не
 * скажет о том, сколько раз это спасёт и сколько раз соврёт.
 *
 * ## Что печатает
 *
 * Поймано из скольких, ложных тревог, фору в секундах. Числа замысла:
 * 18 из 18, одна ложная, 9,1 секунды. Разошлись — код выхода ненулевой.
 *
 * ## Запуск
 *
 *     pnpm exec tsx scripts/dota-replay.ts [путь к папке записи]
 */
import { createReadStream } from 'node:fs';
import { createInterface } from 'node:readline';
import { argv, exit } from 'node:process';

import { readPacket } from '../jarvis/dota/packet';
import { applyPacket, createState } from '../jarvis/dota/state';
import { judgeDanger, judgeGold } from '../jarvis/dota/thresholds';

const ПАПКА = argv[2] ?? 'C:/Users/ariel/Desktop/Джарвис/разведка-доты/запись-2026-09-21-1255';
const ОКНО = 15_000;   // столько ждём смерть после того, как тревога смолкла
const СКЛЕЙКА = 8_000; // тревоги ближе этого — один эпизод

const пакеты = [];
const поток = createInterface({ input: createReadStream(`${ПАПКА}/gsi.jsonl`), crlfDelay: Infinity });
for await (const строка of поток) {
  if (!строка) continue;
  let сырая;
  try { сырая = JSON.parse(строка); } catch { continue; }
  const п = readPacket(сырая.d, сырая.t);
  if (п?.self) пакеты.push(п);
}

const смерти = [];
const эпизоды = [];
let текущий = null;
let состояние = createState();
let золотых = 0;
let золотоГорело = false;

for (let i = 0; i < пакеты.length; i += 1) {
  const п = пакеты[i];
  const былЖив = пакеты[i - 1]?.self?.alive ?? true;
  if (былЖив && п.self.alive === false) смерти.push(п);

  состояние = applyPacket(состояние, п);

  const золото = judgeGold(состояние);
  if (золото.passed === false) { if (!золотоГорело) золотых += 1; золотоГорело = true; }
  else золотоГорело = false;

  const ворота = judgeDanger(п);
  if (ворота.passed === false) {
    if (текущий && п.at - текущий.конец <= СКЛЕЙКА) текущий.конец = п.at;
    else { текущий = { начало: п.at, конец: п.at, clock: п.clock }; эпизоды.push(текущий); }
  }
}

const пойманные = new Map();
const сработавшие = new Set();
for (const с of смерти) {
  const э = эпизоды.find((э) => с.at >= э.начало && с.at - э.конец <= ОКНО);
  if (!э) continue;
  пойманные.set(с, (с.at - э.начало) / 1000);
  сработавшие.add(э);
}
const впустую = эпизоды.length - сработавшие.size;
const форы = [...пойманные.values()];
const средняя = форы.length ? форы.reduce((a, б) => a + б, 0) / форы.length : 0;

console.log(`пакетов: ${пакеты.length}`);
console.log(`героя убивали: ${смерти.length}`);
console.log(`тревог: ${эпизоды.length}, из них впустую: ${впустую}`);
console.log(`поймано: ${пойманные.size} из ${смерти.length}`);
console.log(`фора в среднем: ${средняя.toFixed(1)} с`);
console.log(`реплик про золото: ${золотых}`);

const беды = [];
if (пойманные.size !== смерти.length) беды.push(`поймано ${пойманные.size}, а смертей ${смерти.length}`);
if (впустую > 2) беды.push(`ложных тревог ${впустую}, в замысле одна`);
if (средняя < 7) беды.push(`фора ${средняя.toFixed(1)} с, в замысле 9,1`);
if (золотых > 4) беды.push(`реплик про золото ${золотых}, в замысле две`);

if (беды.length) {
  console.log('');
  console.log('РАЗОШЛОСЬ С ЗАМЫСЛОМ:');
  for (const б of беды) console.log('  -', б);
  exit(1);
}
console.log('');
console.log('числа сошлись с замыслом');
```

## Самопроверка плана

**Покрытие замысла.** Шаги 1–3 замысла («приёмник, состояние, пороги») покрыты задачами 1–6. Оверлей, зрение, команды роутера и порог «могу убить» — это шаги 4–6 замысла, и в этот план они намеренно не входят: они начинаются после того, как числа сойдутся.

**Чего в плане нет и почему.** Порога простоя нет — он отвергнут замером. Стаков нет — нужны точные координаты лагерей. Слота↔героя нет — он нужен только как вход в будущие пороги.

**Согласованность имён.** `DotaPacket`, `MapObject`, `SelfHero`, `DotaEvent`, `DotaState`, `Camp`, `CampPosition`, `DangerRule`, `GoldRule` объявлены по одному разу и используются под теми же именами. `readPacket`, `startReceiver`, `createCamps`, `updateCamps`, `createState`, `applyPacket`, `judgeDanger`, `judgeGold` — тоже.
