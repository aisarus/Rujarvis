# Быстрые правки, начало задачи и надёжность слуха — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сделать повседневную работу с Джарвисом быстрой и не спотыкающейся: мелкие правки в открытом блендере — мгновенными, начало задачи — короче, выдумки распознавателя — отсеянными по замеру, а не по словарю.

**Architecture:** Три независимых куска. Быстрые правки — новая таблица правил рядом с существующими прямыми командами, шлёт в живой сеанс блендера напрямую из голосового моста. Начало задачи — сперва замер, затем один точечный блок в промпте. Слух — доля речи едет вместе с записью из страницы микрофона и отбрасывает куски, в которых говорить было нечего.

**Tech Stack:** TypeScript строгий, vitest, Electron, MCP (`@modelcontextprotocol/sdk`), Blender 5.2 через свой живой сеанс. Комментарии и тексты — по-русски, как во всём проекте.

**Spec:** [docs/superpowers/specs/2026-09-19-быстрые-правки-и-надёжность-design.md](../specs/2026-09-19-быстрые-правки-и-надёжность-design.md)

## Global Constraints

- Комментарии, имена в строках и тексты для человека — по-русски. Идентификаторы — английские, как в существующем коде (`StoryLine`, `PlanStep`, `StepState = 'ждёт'`).
- Каждое правило закрыто тестом. Тест, который не падает на сломанном коде, — украшение.
- **Обратные слэши не переживают перезаписи файла.** `'\\'` схлопывается, `\n` в heredoc превращается в настоящий перенос и рвёт строковый литерал. Сегодня это ломало сборку трижды. В путях — прямые слэши; где нужен именно обратный — `String.fromCharCode(92)`.
- Обратная кавычка внутри шаблонной строки рвёт её пополам. В коде, который сам генерирует текст (страница микрофона, слушатель блендера), обратных кавычек быть не должно — на это есть тесты.
- Файлы проекта с `\r\n`; замены это учитывают.
- Никакой модели в быстром пути. Модель, пишущая Python в открытую сцену человека, — способ однажды стереть ему работу.
- Порог и число, попавшие в код, должны быть замерены, а замер — записан комментарием рядом.

```typescript
/**
 * Сколько времени уходит, прежде чем агент начнёт делать дело.
 *
 * Замер 19 сентября на задаче про блендер: двенадцать секунд до первого
 * действия, меняющего мир. Из них `ToolSearch` вызывался четыре раза за
 * задачу — агент искал инструменты, которые у него уже были.
 *
 * Здесь считается именно ориентация: поиск инструментов, загрузка навыка,
 * обращение к памяти. Резать её наугад значит убрать полезное и оставить
 * дорогое, поэтому сперва — числа.
 */

import type { BackendEvent } from '../backends/types';

/** Инструменты, которые мир не меняют: это подготовка, а не дело. */
const ORIENTATION = ['ToolSearch', 'Skill', 'mcp__jarvis-desktop__recall', 'TodoWrite'];

function isOrientation(name: string): boolean {
  return ORIENTATION.some((prefix) => name.startsWith(prefix));
}

export class StartupTiming {
  private first: number | null = null;
  private readonly counts = new Map<string, number>();

  constructor(private readonly startedAt: number) {}

  saw(event: BackendEvent, at: number): void {
    if (event.type !== 'tool') return;
    const name = event.name ?? '';
    if (!name) return;

    if (isOrientation(name)) {
      const key = name.startsWith('mcp__jarvis-desktop__') ? name.slice(21) : name;
      this.counts.set(key, (this.counts.get(key) ?? 0) + 1);
      return;
    }
    if (this.first === null) this.first = at - this.startedAt;
  }

  get firstUsefulMs(): number | null {
    return this.first;
  }

  /** Строка для журнала. `null` — дела ещё не было, и говорить нечего. */
  report(): string | null {
    if (this.first === null) return null;
    const spent = [...this.counts.entries()]
      .sort((left, right) => right[1] - left[1])
      .map(([name, times]) => `${name} ${times}`)
      .join(', ');
    return `${(this.first / 1000).toFixed(1)} с до первого дела` + (spent ? ` (ориентация: ${spent})` : '');
  }
}
```

```typescript
/**
 * Отличается ли выдумка от речи по доле речи в куске.
 *
 * Читает журнал дня, раскладывает распознанное на две кучи — известные выдумки
 * и всё остальное — и печатает доли речи. Если кучи не разделяются, порога нет,
 * и честный вывод — оставить словарь.
 */

import { readFileSync } from 'node:fs';

const LOG = 'C:/Users/ariel/AppData/Local/Rujarvis/data/jarvis.log';

const ВЫДУМКИ = [
  'субтитры', 'продолжение следует', 'продолжение в следующей серии',
  'спасибо за просмотр', 'подписывайтесь', 'dimatorzok',
];

const строки = [...readFileSync(LOG, 'utf8').matchAll(
  /услышал за \d+ мс \([\d.]+ с речи[^)]*\)(?:, речи (\d+)%)?: (.*)/g,
)];

const выдумки: number[] = [];
const речь: number[] = [];

for (const [, доля, текст] of строки) {
  if (доля === undefined) continue;
  const число = Number(доля);
  const это = ВЫДУМКИ.some((слово) => (текст ?? '').toLowerCase().includes(слово));
  (это ? выдумки : речь).push(число);
}

function свод(имя: string, числа: number[]): void {
  if (числа.length === 0) {
    console.log(`${имя}: нет примеров`);
    return;
  }
  const по = [...числа].sort((a, b) => a - b);
  const медиана = по[Math.floor(по.length / 2)];
  const макс = по[по.length - 1];
  console.log(`${имя}: ${числа.length} шт, мин ${по[0]}%, медиана ${медиана}%, макс ${макс}%`);
}

свод('выдумки', выдумки);
свод('речь', речь);

const самаяГромкаяВыдумка = выдумки.length ? Math.max(...выдумки) : null;
const самаяТихаяРечь = речь.length ? Math.min(...речь) : null;
console.log('');
if (самаяГромкаяВыдумка !== null && самаяТихаяРечь !== null) {
  console.log(
    самаяГромкаяВыдумка < самаяТихаяРечь
      ? `РАЗДЕЛЯЮТСЯ: порог между ${самаяГромкаяВыдумка}% и ${самаяТихаяРечь}%`
      : `НЕ РАЗДЕЛЯЮТСЯ: выдумка доходит до ${самаяГромкаяВыдумка}%, речь опускается до ${самаяТихаяРечь}%`,
  );
} else {
  console.log('мало данных: поговорите с Джарвисом и прогоните снова');
}
```

```typescript
/**
 * Мелкие правки в открытом блендере — без агента.
 *
 * ## Зачем
 *
 * «Сделай её синей» — это одна строчка на Python. Сегодня ради неё поднимается
 * весь агент: минута-две от фразы до цвета. Человек назвал это первым местом,
 * где ожидание мешает работать.
 *
 * ## Почему правилами, а не моделью
 *
 * Модель, пишущая Python в открытую сцену человека, — способ однажды стереть
 * ему работу. Здесь таблица: что не в ней, то молча уходит агенту, как раньше.
 * Человек не видит границы — он видит, что часть просьб стала мгновенной.
 *
 * Разбор устроен как у прямых команд (`jarvis/control/commands.ts`): точное
 * совпадение с очисткой заполнителей. Ошибка в сторону «не узнал» стоит
 * секунды ожидания; в обратную — испорченной сцены.
 */

const FILLER = ['ну', 'вот', 'уже', 'пожалуйста', 'давай', 'сейчас', 'там', 'же', 'ка'];

const COLOURS: Record<string, [string, string]> = {
  красн: ['0.9, 0.1, 0.1', 'красным'],
  син: ['0.1, 0.2, 0.9', 'синим'],
  зелен: ['0.1, 0.8, 0.2', 'зелёным'],
  желт: ['0.95, 0.85, 0.1', 'жёлтым'],
  бел: ['0.95, 0.95, 0.95', 'белым'],
  черн: ['0.05, 0.05, 0.05', 'чёрным'],
  оранжев: ['0.95, 0.45, 0.1', 'оранжевым'],
  фиолетов: ['0.5, 0.2, 0.8', 'фиолетовым'],
  розов: ['0.95, 0.5, 0.7', 'розовым'],
  сер: ['0.5, 0.5, 0.5', 'серым'],
};

const NUMBERS: Record<string, number> = {
  один: 1, одну: 1, два: 2, две: 2, три: 3, четыре: 4, пять: 5,
  шесть: 6, семь: 7, восемь: 8, девять: 9, десять: 10,
  пятнадцать: 15, двадцать: 20, тридцать: 30, сорок: 40,
  пятьдесят: 50, девяносто: 90, сто: 100, сто восемьдесят: 180,
};

export interface LiveEdit {
  kind: 'python';
  code: string;
  /** Что сказать человеку. Коротко: он смотрит на экран, а не слушает отчёт. */
  said: string;
}

function words(utterance: string): string[] {
  return utterance
    .toLowerCase()
    .replace(/ё/gu, 'е')
    .replace(/[^\p{L}\p{N}\s-]/gu, ' ')
    .split(/\s+/u)
    .filter((word) => word && !FILLER.includes(word));
}

/** Число словом или цифрой. `null` — числа не назвали. */
function numberIn(parts: readonly string[]): number | null {
  for (const part of parts) {
    if (/^\d+$/u.test(part)) return Number(part);
    const named = NUMBERS[part];
    if (named !== undefined) return named;
  }
  return null;
}

/**
 * Кого правим.
 *
 * «Её», «его», «это» — активный объект. Названное вслух ищется по имени, и
 * поиск нестрогий: человек говорит «ракету», а объект зовётся «Ракета_корпус».
 */
const PRONOUNS = ['её', 'ее', 'его', 'это', 'эту', 'этот', 'их'];

function targetCode(parts: readonly string[], used: readonly string[] = []): string {
  // Слова, уже разобранные как цвет или число, целью быть не могут. Без этого
  // «сделай её синей» ищет в сцене объект по имени «синей» и не находит
  // ничего — а человек видит, что ничего не покрасилось.
  const named = parts.find(
    (word) =>
      word.length > 3 &&
      !PRONOUNS.includes(word) &&
      !(word in NUMBERS) &&
      !used.includes(word) &&
      !Object.keys(COLOURS).some((stem) => word.startsWith(stem)),
  );
  if (!named) return 'bpy.context.active_object';

  const stem = named.slice(0, Math.max(4, named.length - 2));
  return `next((o for o in bpy.data.objects if ${JSON.stringify(stem)} in o.name.lower()), bpy.context.active_object)`;
}

const HEAD = 'import bpy\nfrom math import radians\n';
const GUARD = 'if о is None:\n    raise RuntimeError("не понял, что править: ничего не выбрано")\n';

export function parseLiveEdit(utterance: string): LiveEdit | null {
  const parts = words(utterance);
  if (parts.length === 0) return null;
  const joined = parts.join(' ');

  // Анимация — раньше остального: «останови анимацию» не должно попасть в
  // таблицу движения.
  if (/^(играй|запусти|включи) анимаци/u.test(joined)) {
    return {
      kind: 'python',
      code: `${HEAD}bpy.ops.screen.animation_play()`,
      said: 'Играю.',
    };
  }
  if (/^(останови|стоп|выключи) анимаци/u.test(joined)) {
    return {
      kind: 'python',
      code: `${HEAD}bpy.ops.screen.animation_cancel(restore_frame=False)`,
      said: 'Остановил.',
    };
  }

  const VERBS = [
    'сделай', 'покрась', 'закрась', 'в', 'раза', 'раз', 'на', 'цвет',
    'подними', 'опусти', 'поверни', 'разверни', 'крутни', 'увеличь', 'уменьши',
    'удали', 'спрячь', 'скрой', 'покажи', 'больше', 'меньше', 'выше', 'ниже',
    'вверх', 'вниз', 'вправо', 'влево', 'анимацию', 'анимация',
  ];
  const rest = parts.filter((word) => !VERBS.includes(word));
  const target = targetCode(rest, VERBS);

  // Цвет.
  const colour = Object.entries(COLOURS).find(([stem]) =>
    rest.some((word) => word.startsWith(stem)),
  );
  if (colour && /сделай|покрась|закрась|цвет/u.test(joined)) {
    const [, [rgb, said]] = colour;
    return {
      kind: 'python',
      code:
        `${HEAD}о = ${target}\n${GUARD}` +
        `м = о.active_material or bpy.data.materials.new("Цвет")\n` +
        `if not о.data.materials: о.data.materials.append(м)\n` +
        `м.use_nodes = True\n` +
        `у = м.node_tree.nodes.get("Principled BSDF")\n` +
        `if у: у.inputs[0].default_value = (${rgb}, 1)\n` +
        `м.diffuse_color = (${rgb}, 1)\n` +
        `print("покрасил", о.name)`,
      said: `Сделал ${said}.`,
    };
  }

  // Движение.
  const moves: Array<[RegExp, string]> = [
    [/подними|вверх|выше/u, 'location.z += '],
    [/опусти|вниз|ниже/u, 'location.z -= '],
    [/вправо/u, 'location.x += '],
    [/влево/u, 'location.x -= '],
  ];
  const move = moves.find(([pattern]) => pattern.test(joined));
  if (move) {
    const by = numberIn(rest) ?? 1;
    return {
      kind: 'python',
      code: `${HEAD}о = ${target}\n${GUARD}о.${move[1]}${by}\nprint("сдвинул", о.name)`,
      said: 'Сдвинул.',
    };
  }

  // Поворот.
  if (/поверни|разверни|крутни/u.test(joined)) {
    const by = numberIn(rest) ?? 90;
    return {
      kind: 'python',
      code: `${HEAD}о = ${target}\n${GUARD}о.rotation_euler.z += radians(${by})\nprint("повернул", о.name)`,
      said: `Повернул на ${by}.`,
    };
  }

  // Размер.
  if (/увеличь|больше|уменьши|меньше/u.test(joined)) {
    const by = numberIn(rest) ?? 2;
    const factor = /уменьши|меньше/u.test(joined) ? `1/${by}` : `${by}`;
    return {
      kind: 'python',
      code:
        `${HEAD}о = ${target}\n${GUARD}` +
        `к = ${factor}\nо.scale = tuple(з * к for з in о.scale)\nprint("размер", о.name)`,
      said: 'Готово.',
    };
  }

  // Видимость и удаление.
  if (/^удали/u.test(joined)) {
    return {
      kind: 'python',
      code: `${HEAD}о = ${target}\n${GUARD}bpy.data.objects.remove(о, do_unlink=True)\nprint("удалил")`,
      said: 'Удалил.',
    };
  }
  if (/^(спрячь|скрой)/u.test(joined)) {
    return {
      kind: 'python',
      code: `${HEAD}о = ${target}\n${GUARD}о.hide_viewport = True\nprint("спрятал", о.name)`,
      said: 'Спрятал.',
    };
  }
  if (/^покажи/u.test(joined) && !/папк|файл|лог|план/u.test(joined)) {
    return {
      kind: 'python',
      code: `${HEAD}о = ${target}\n${GUARD}о.hide_viewport = False\nprint("показал", о.name)`,
      said: 'Показал.',
    };
  }

  return null;
}
```

## Порядок и почему он такой

Задачи 1–3 — про то, что мешает каждый день, и они независимы друг от друга.
Задача 4 зависит от 3 (нужны данные), задача 5 — от 4 (нужен порог) и может не
понадобиться вовсе. Задачи 6–7 связаны: таблица без подключения бесполезна,
подключение без таблицы невозможно. Задача 8 самостоятельна и делается когда
угодно.

Правки (6–7) идут после замеров (1–3) потому, что они приятнее, но реже
спасают: выключенный микрофон и выдуманные субтитры съели вечер целиком, а
ожидание цвета — секунды.
