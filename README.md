# Rujarvis

[English version](README.en.md)

**Конспекты лекций для тех, кто учится на чужом языке.**

Rujarvis записывает лекцию — в аудитории с микрофона ноутбука или в Zoom звуком
компьютера, — расшифровывает её у вас на компьютере и пишет в Obsidian конспект
на вашем языке: разделы со временем, итог, понятия с термином лектора, вопросы к
экзамену. Лекция на иврите — конспект по-русски. Потом по этой лекции можно
учиться прямо в его окне «Учёба».

- **Звук остаётся у вас.** Распознаёт whisper.cpp на вашем компьютере. Для иврита
  — дообученная модель [ivrit.ai](https://huggingface.co/ivrit-ai): на открытых
  записях университетских лекций 14% ошибок в словах против 35% у обычной small.
  Для других языков — общая large-v3-turbo.
- **Пишет ваша подписка.** Claude Code (Claude Pro) или Codex (ChatGPT Plus), в
  которые вы вошли сами; хватит одного. Никаких API-ключей, аккаунтов у нас и
  телеметрии. Наружу уходит только текст расшифровки и файлы, которые вы сами дали
  на разбор.
- **Записи не верит вслепую.** Распознавание путает числа и буквы, ошибается и сам
  лектор. Числа, формулы, обозначения и названные ответы сверяются с самой лекцией
  и со знанием предмета, а каждая правка видна, с минутой:
  *(⚠ 1:42:39: лектор сказала «1 и 3», по расчёту 1 и 4 — сверить со слайдом)*.
  Формулы — в LaTeX, их рисует Obsidian.
- **Лекция не теряется.** Звук сразу пишется на диск. Закрыли посреди пары — при
  следующем запуске конспект допишется сам. Запись с телефона или видео курса —
  кнопка «Из файла…».
- **Потом — учёба.** Окно «Учёба»: что повторить сегодня, квиз на языке лекции с
  переводом и голосом лектора с той минуты, карточки, тренировка экзамена, задачи.
- **Файлы курса тоже.** Силлабус, статья, задание: бросили файл — в Obsidian разбор
  на вашем языке, а в «Учёбе» вопросы по нему.

Конспект — на русском или английском. Лекция — на иврите, английском, русском и
других языках, у каждого курса свои настройки. Живьём проверено так: иврит →
русский (см. [честный статус](#честный-статус)).

**И ещё это голосовой помощник.** Полная версия слушает команды на русском и
английском: *«закрой это окно»*, *«прокрути вниз»*, *«найди, почему не собирается
проект, и почини»*. Простое выполняется сразу, без модели и без интернета.
Сложное — настоящая работа Claude Code на вашем экране, в браузере и в файлах.
Перед тем как потратить деньги, написать кому-то или сделать необратимое, Джарвис
спрашивает вслух. Подробно — [как с ним говорить](#как-с-ним-говорить) и
[о чём он спросит](#о-чём-он-спросит). Вариант «только конспекты» ставится без
всего этого.

## Установка

### Что нужно для конспектов

- **Windows 10/11 с видеокартой NVIDIA или Mac с macOS 13 и новее.** На Windows без
  NVIDIA установщик распознавание не ставит, и лекция только записывается. Поставить
  можно кнопкой в настройках, но без видеокарты это не проверено и, скорее всего, во
  много раз медленнее самой лекции.
- **Подписка Claude Pro или ChatGPT Plus.** Claude Code или Codex мастер первого
  запуска поставит кнопкой и сам проверит слух и модель до первой пары.
- **Obsidian — желательно.** Конспекты ложатся в открытое хранилище, в папку
  `Лекции`. Нет Obsidian — в папку результатов Джарвиса, теми же файлами `.md`.
- **Место на диске.** Несколько гигабайт на программы и модели; ещё около 280 МБ на
  полуторачасовую пару. Звук старше недели удаляется сам, конспект и расшифровка
  остаются.
- **Для Zoom на маке — macOS 14.2 и новее.** На старой лекция из Zoom пишется
  микрофоном.

### Только конспекты

Для студента, которому нужен конспектор, а не голосовой помощник: без слуха
команд, голоса и рук на компьютере. Строка для лекций на иврите; другой язык —
другой код (`en`, `ru`, …).

Windows, в PowerShell:

```powershell
$f = "$env:TEMP\rujarvis-install.ps1"; irm https://raw.githubusercontent.com/aisarus/Rujarvis/main/install.ps1 -OutFile $f; & $f -Edition notes -LectureLanguage he
```

macOS, в Терминале (с подпиской ChatGPT добавьте `--codex`):

```bash
f=/tmp/rujarvis-install.sh; curl -fsSL https://raw.githubusercontent.com/aisarus/Rujarvis/main/install.sh -o "$f" && bash "$f" --notes --lecture-language he
```

Что будет дальше и что нажимать —
[памятка для мака](docs/jarvis/mac-tester.md) и
[установка](docs/jarvis/install.md#только-конспекты).

### Джарвис целиком

Конспекты и голосовой помощник вместе. Windows 10/11, одна строка в PowerShell.

Где его взять: нажмите **Win**, наберите `PowerShell`, откройте «Windows
PowerShell». Права администратора не нужны. Скопируйте строку целиком, вставьте
(**Ctrl+V** или правой кнопкой) и нажмите Enter.

```powershell
$f = "$env:TEMP\rujarvis-install.ps1"; irm https://raw.githubusercontent.com/aisarus/Rujarvis/main/install.ps1 -OutFile $f; & $f
```

Английский по умолчанию:

```powershell
$f = "$env:TEMP\rujarvis-install.ps1"; irm https://raw.githubusercontent.com/aisarus/Rujarvis/main/install.ps1 -OutFile $f; & $f -Language en
```

Скрипт сначала скачивается в файл, а не выполняется из строки. Причина
прикладная: у него BOM, без которого Windows PowerShell 5.1 читает русские
сообщения как ANSI и не разбирает файл вовсе. Но `irm | iex` получает файл
СТРОКОЙ, и BOM попадает в её начало — открывающий комментарий перестаёт
распознаваться, и установка падает с «Непредвиденная лексема». Через файл BOM
работает как задуман, и параметры пишутся обычным способом.

Установщик сам поставит Git и Node.js, если их нет, соберёт приложение, скачает
модель распознавания под ваш компьютер и голос, добавит **Rujarvis** в меню
«Пуск» и запустит его. Права администратора, компилятор C++ и Rust не нужны.
Повторный запуск обновляет установку.

macOS, одна строка в Терминале.

Где его взять: нажмите **Cmd+Space**, наберите `Терминал` (или `Terminal`),
Enter. Он встроен в macOS — ставить нечего. Скопируйте строку целиком, вставьте
(**Cmd+V**) и нажмите Enter. Пароль система спросит один раз, если понадобится
Homebrew.

```bash
f=/tmp/rujarvis-install.sh; curl -fsSL https://raw.githubusercontent.com/aisarus/Rujarvis/main/install.sh -o "$f" && bash "$f"
```

Тоже через файл, а не через `curl | bash`. Причина замерена: у скрипта,
пришедшего по конвейеру, `stdin` уже пуст, и он не может ничего спросить —
вопрос от Homebrew, corepack или pnpm молча провалится вместо того, чтобы
дойти до вас. Файлом `stdin` остаётся вашим терминалом, и ключи пишутся
обычным способом, без `-s --`.

Тот же порядок: Homebrew, Git и Node.js ставятся сами, если их нет, приложение
собирается, модели речи скачиваются, **Rujarvis** появляется в `~/Applications`.
Голос, разговор и работа через Claude Code работают так же, как на Windows.
Управление чужими окнами — фокус, клавиши, снимки, чтение элементов — работает
и на маке: там это System Events и CoreGraphics вместо Windows API. Замер на
настоящем маке 24.09.2026: из шестнадцати сценариев приёмки прошло тринадцать,
двум нечем мерить (они про реестр Windows), один не прошёл — сетка нажатий не
накрывает строку меню и док.

macOS спросит два разрешения отдельно: «Универсальный доступ» (окна, мышь,
клавиши) и «Запись экрана» (снимки). Без первого CGEvent не падает, а **молча
ничего не делает** — поэтому Джарвис спрашивает разрешение сам, до первой
операции, а не выясняет это по факту.

При первом запуске короткая настройка проведёт по шагам: язык, вход в Claude
Code, модели речи, проверка микрофона. Потом всё меняется в трее → **Настройки**.

**Что нужно для ИИ-части.** Прямые команды (ниже) работают без всяких аккаунтов.
Для настоящей работы нужен [Claude Code](https://claude.ai/code) или Codex со
своей подпиской. Есть Claude Code — работает он; нет — его целиком заменяет
Codex. Одно другое не подменяет: исчерпанный лимит Claude не тратит подписку
Codex. Мы не берём денег и не стоим между вами и моделью.

**Своя модель вместо подписки** — для мощных компьютеров. Если у вас уже
запущены Ollama (0.14+), LM Studio или llama.cpp (`llama-server --jinja`),
укажите адрес и имя модели в **Настройки → Агенты**: Джарвис направит на неё
тот же Claude Code, вход в аккаунт Anthropic не нужен, красные линии и
инструменты работают так же. Кнопка «Проверить и включить» спрашивает модель
по-настоящему и не включит ту, что не умеет вызывать инструменты. Принимается
только адрес на этом компьютере или в домашней сети; модель Джарвис не качает.

## Как идёт лекция

На плашке — кнопка **● Конспект**, в аудитории вслух не покомандуешь. Она
спрашивает, откуда звук: «В аудитории (микрофон)» или «Zoom (звук компьютера)».
Заметка сразу открывается в Obsidian и растёт на глазах: расшифровка — кусок за
куском, раздел конспекта — раз в пять минут. **■ Закончить конспект** дописывает
итог и раскладывает лекцию по курсу:

```
Лекции/
  Статистика/
    Статистика.md                        страница курса
    2026-11-03 — Меры центра.md          конспект
    2026-11-03 — Меры центра — расшифровка.md
    2026-11-03 — Меры центра.wav         звук: можно включить с нужной минуты
```

- **Вид конспекта** — на выбор, в настройках: «Разбор», «Сначала проверь себя» и
  «Язык лекции рядом» (фразы лектора с переводом и словарь лекции).
- **Курс** угадывается по расписанию и по содержанию; ошибся — кнопка «Курс: … ▾».
- **Лектора слышно плохо** — плашка скажет об этом на первых минутах, а не вечером
  над пустым конспектом. Лучшая страховка — запись с телефона на первой парте и
  «Из файла…».

[Подробно о конспекте](docs/jarvis/lecture-notes.md) ·
[об «Учёбе»](docs/jarvis/study.md) ·
[о разборе файлов](docs/jarvis/document-pipeline.md).

## Как с ним говорить

Это о полной версии. Не нужно учить язык команд, как в Talon. Не нужен английский,
как в Windows Voice Access. Не нужен облачный сервис для распознавания: речь
распознаётся и синтезируется на вашем компьютере.

| Скажите | Что будет |
| --- | --- |
| **Джарвис** | Проснётся; следующую минуту можно без имени |
| `Ctrl+Space` | Нажать, сказать, нажать ещё раз |
| `Ctrl+M` | Выключить / включить микрофон |
| **стоп** | Немедленно остановить любую работу |
| **тишина** | Замолчать и закончить разговор |
| *что ты умеешь* | Показать все прямые команды |

**Прямые команды** — мгновенно, без модели: прокрутка, клавиши, вкладки, окна,
клик по названию кнопки, нумерованная сетка поверх экрана, диктовка с правкой
(«удали последнее слово», «новая строка»), запуск и закрытие программ, звук,
мелкие правки в открытом Blender («сделай её синей», «поверни на сорок пять»),
конспект лекции («конспектируй лекцию по матанализу» — см. ниже).
Всего больше семидесяти фраз, и каждую проверяет тест.

Всё остальное уходит разговору, который помнит нить и управляет работой: её можно
поправить на ходу, поставить на паузу или остановить. Разговор ведёт живая
сессия Claude Code, а если его нет — Codex (ход дольше: процесс на каждую реплику).

«Стоп», «тишина», «пауза», «продолжай» и ответы «да/нет» понимаются на обоих
языках, какой бы ни был выбран.

## О чём он спросит

Четыре красные линии: трата денег, сообщения другим людям, системные файлы и
разрушительные или «внешние» команды (`git push`, `rm -rf`, `curl | sh` и
подобные). Всё остальное делается без вопросов.

Проверяются они дважды — в коде, а не в промпте. Сначала сказанная фраза, ещё до
запуска агента. Потом **каждое действие агента** проходит через хук `PreToolUse`
Claude Code: он смотрит на конкретную команду, файл или кнопку и спрашивает вас
голосом перед всем, что на красной линии. Нет ответа — значит нет. Это важно:
агент читает веб-страницы и файлы, а они могут попытаться уговорить его сделать
то, чего вы не просили.

Чего хук не видит: клик по координатам или по номеру элемента не говорит, что
именно нажимается. Codex работает в своей песочнице (`workspace-write`: запись
только в рабочую папку) и инструментов рабочего стола не получает; доступ в
сеть из песочницы задаётся настройками самого Codex, а не Джарвисом —
проверьте их, если это важно. Подробно —
[docs/jarvis/architecture.md](docs/jarvis/architecture.md).

## Где что лежит

Всё в одной папке, `%LOCALAPPDATA%\Rujarvis`:

| Папка | Что там |
| --- | --- |
| `src\` | Само приложение |
| `data\` | Настройки, память, журнал действий, план, ваши постоянные указания (`характер.md`) |
| `logs\jarvis.log` | Лог; в трее есть **Открыть лог** |
| `models\` | Распознавание (`whisper\`) и голоса (`voices\`) |
| `cua-driver\` | Драйвер окон |

Файлы, которые агент делает для вас, лежат в папке **Джарвис** на рабочем
столе — по разделам (Документы, Таблицы, Картинки, Видео, Код…), с подпапкой на
каждую задачу.

В лог пишутся команды, обращённые к Джарвису, — но не ваша диктовка и не
разговоры вокруг. Если он плохо слышит, в **Настройки → Папки и лог** можно
включить «писать всё».

### Удалить

Windows, в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Rujarvis\src\uninstall.ps1"
```

macOS, в Терминале:

```bash
bash "$HOME/Library/Application Support/Rujarvis/src/uninstall.sh"
```

Удаление закрывает Джарвиса, убирает ярлыки, автозапуск и всю его папку.
Папку результатов **Джарвис** на рабочем столе и вход в Claude Code и Codex не
трогает.

## Приватность

Речь распознаётся и синтезируется локально, звук лекции остаётся на диске. С
компьютера уходит только то, что вы отправляете в Claude Code или Codex, в которые
вошли сами, — ровно как при работе с ними напрямую: чтобы написать конспект, туда
идёт текст расшифровки. И звук — только если вы сами включили распознавание не
на этой машине: облачное (переключатель «Где распознаётся речь» в настройках,
вкладка «Речь», плюс ключ `ELEVENLABS_API_KEY`; ключ без переключателя ничего
не включает) или свой сервер whisper.cpp по сети (`JARVIS_GPU_STT` с адресом не
на `localhost`). Телеметрии нет.

## Честный статус

Это ранняя версия — идёт закрытая бета.

- **Конспект живьём.** Владелец проекта пишет им свои пары в университете на
  Windows с NVIDIA: лекции на иврите, конспект по-русски, микрофон ноутбука в
  аудитории. Последняя проверка — 03.11.2026, три пары, самая длинная 2:30.
  «Учёба» работает на тех же лекциях. Другие сочетания языков живьём почти не
  ходили.
- **Проверка записи — работа модели, а не гарантия.** На статистике 03.11 итог
  собрал верную формулу медианы и пометил неверный ответ лектора. Но в разделах
  бывает непомеченное («частота (плотность)»), а время в пометке иногда на строку
  позже. Отсутствие пометки не значит, что ошибки нет: сверяйте со слайдом.
- **Zoom на Windows** замерен петлёй вывода: тишина без звука, сигнал на фразе из
  колонок.
- **Codex** проверен вживую (codex-cli 0.153.4, подписка ChatGPT): лекция на иврите
  в 8 минут, «Учёба», открытый ответ, разбор docx. PDF через Codex пока читается
  только на маке.
- **Мак.** В CI на Apple Silicon и Intel: установка `--notes --codex`, конспектор с
  подставным микрофоном (`pnpm jarvis:notes-check`, 8 из 8), PDFKit. **На живом маке
  ещё не проверены:** микрофон и разрешения macOS, звук Zoom, скорость распознавания
  на настоящем Intel (виртуальные машины CI об этом не говорят), разбор PDF через
  Codex целиком. Голосовое управление на маке замерено отдельно, см. установку.
- **Голосовой помощник.** Приложение, настройка, голосовой конвейер, хук красных
  линий и оба языка проверены в CI на Windows и Linux и вручную под виртуальным
  дисплеем; живьём он работает на Windows владельца. Установку целиком прошёл первый
  тестер на своей Windows; планового прогона на чистых Windows 10 и 11 ещё не было.
- Замер синтезом речи и распознаванием Whisper `base` (`pnpm jarvis:roundtrip`):
  русский 10/12, английский 9/12, все слова остановки — на обоих языках.
  Живой микрофон и модель побольше дают лучше; синтетическая речь — нижняя
  граница.
- Распознавание на видеокарте — по желанию: `pnpm jarvis:gpu-stt` ставит
  whisper.cpp и модель small (Windows — сборка с CUDA для видеокарт NVIDIA,
  около 900 МБ; мак — `brew install whisper-cpp`, Metal) в папку Джарвиса, и
  Джарвис сам поднимает свой сервер на этом компьютере. Проверка —
  `pnpm jarvis:gpu-stt-check`. Без установки команды распознаются на процессоре, а
  лекции только записываются. Свой сервер по сети — `JARVIS_GPU_STT`.
- Модель для лекций ставится установщиком и кнопкой в настройках, вручную —
  `pnpm jarvis:lecture-model` (574 МБ, для иврита ivrit.ai — 1,6 ГБ до сжатия).
  Вопросы «Учёбы» готовит Claude Code или Codex по подписке после каждой лекции.
  Формулы в окне «Учёба» — читаемым текстом (`x₀`, `a/b`), настоящие дроби рисует
  Obsidian.

Нашли ошибку — [issue](https://github.com/aisarus/Rujarvis/issues) с логом
(прочитайте его перед отправкой).

## Для разработчиков

```bash
pnpm install
pnpm build            # esbuild, несколько секунд
pnpm start            # приложение
pnpm typecheck
pnpm test             # ~2650 тестов
pnpm jarvis:roundtrip -- --en   # голос по кругу на настоящих моделях
```

| Папка | Что делает |
| --- | --- |
| `app/` | Приложение Electron: трей, настройки и онбординг, голосовой мост, оверлеи, окно учёбы |
| `jarvis/lecture` | Запись лекции, разделы и итог конспекта, курсы, восстановление |
| `jarvis/study` | Заготовка вопросов, квиз, карточки, экзамен, шкала знания |
| `jarvis/notes`, `jarvis/documents` | Оформление заметок Obsidian и разбор файлов курса |
| `jarvis/backends` | Адаптеры Claude Code / Codex, тёплые сессии, цепочка запасных |
| `jarvis/router` | Понимает, что нужно просьбе и кто её возьмёт |
| `jarvis/risk` | Классы риска, политика красных линий и хук на действия |
| `jarvis/voice` | Имя, стоп-слова, распознавание и синтез, фильтр шума |
| `jarvis/control` | Прямые команды и справочник команд |
| `jarvis/desktop` | MCP-сервер: экран, браузер, окна, Blender и Krita для агента |
| `jarvis/dialogue` | Живой разговор и его рычаги |
| `jarvis/locale` | Русский / английский |
| `jarvis/setup` | Пути, настройки, онбординг |

Две привычки этого кода: **сначала замерь, потом утверждай** — проверки
отвечают «прошло», «не прошло» или «нечем измерить»; и **комментарии объясняют
зачем, а не что**.
