# Support

Use GitHub Discussions for questions and GitHub Issues for reproducible
defects. Search existing reports first.

When you attach `jarvis.log` (in `%LOCALAPPDATA%\Rujarvis\data`), read it
before posting: it contains the commands you gave the assistant and the paths
of files it touched. Never post credentials or recordings of other people.

Security problems go through the private channel described in
[SECURITY.md](SECURITY.md).

Rujarvis is a community project maintained in spare time; there is no SLA.
