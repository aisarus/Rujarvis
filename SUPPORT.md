# Support

Use GitHub Discussions for questions and GitHub Issues for reproducible
defects. Search existing reports first.

When you attach `jarvis.log` (tray → **Open log**, or
`%LOCALAPPDATA%\Rujarvis\logs\jarvis.log`), read it before posting: it
contains the commands you gave the assistant and the paths of files it
touched — and everything that was said, if you switched speech logging to
*everything*. Never post credentials or recordings of other people.

Security problems go through the private channel described in
[SECURITY.md](SECURITY.md).

Rujarvis is a community project maintained in spare time; there is no SLA.
