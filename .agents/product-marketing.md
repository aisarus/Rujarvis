## Product Overview
**One-liner:** Голосовой ассистент, которому можно доверить компьютер: говорите по-русски как человеку — простое он делает сам, сложное поручает Claude Code, опасное — только с вашего «да».

**What it does:** Rujarvis — голосовой ассистент для Windows в трее. Простое
(окна, прокрутка, клики по названию кнопки, диктовка, запуск программ) делает
сразу, локально и без интернета. Сложное («найди, почему не собирается проект, и
почини», «собери отчёт по этим файлам») отдаёт Claude Code на подписке человека
и делает на его экране, в браузере и в файлах. Перед тратой денег, письмом людям
и необратимыми командами спрашивает вслух.

**Product category:** голосовое управление компьютером; голосовой ассистент для
Windows; ИИ-агент для рабочего стола. Как ищут: «голосовое управление
компьютером», «аналог Talon на русском», «голосовой ассистент для ПК»,
«Джарвис для Windows», «управлять Claude Code голосом».

**Product type:** десктопное приложение с открытым кодом (Apache-2.0), Windows 10/11.

**Business model:** бесплатно. Прямые команды не требуют никаких аккаунтов. Для
ИИ-части нужна своя подписка Claude Code (или Codex как запасной вариант) — мы не
берём денег и не стоим между человеком и моделью.

## Target Audience
**Target companies:** не B2B. Частные пользователи Windows, русскоязычные.

**Decision-makers:** сам пользователь.

**Primary use case:** управлять компьютером и поручать работу голосом, когда руки
заняты, устали или не могут.

**Jobs to be done:**
- Делать рутину на компьютере, не отрываясь от главного («открой почту», «прокрути вниз», «закрой это окно»).
- Поручить агенту задачу целиком голосом и не сидеть над ним («почини билд», «найди и скачай»).
- Работать с компьютером, когда клавиатура и мышь недоступны или болезненны.

**Use cases:**
- Разработчик говорит «почини тесты», пока читает код; просит открыть браузер и найти ошибку.
- Человек с травмой рук или RSI управляет окнами, диктует текст, жмёт кнопки по названию.
- 3D-художник в Blender: «сделай её синей», «подними на три», «поверни на сорок пять».
- Геймер/стример: запускает и закрывает программы, не сворачивая игру.

## Problems & Pain Points
**Core problem:** русских голосовых ассистентов много, но они либо работают по
списку команд, либо болтают с моделью и настоящей работы не делают. А агенту,
который работу делает, страшно отдать компьютер: он может купить, удалить или
написать кому-то, и никто его не остановит.

**Why alternatives fall short:**
- Talon — основная модель только английская; другие языки только для диктовки через сторонние движки; команды надо учить и писать скриптами.
- Windows Voice Access — русского языка нет.
- Typle, Speechka, «Горыныч», навыки Алисы — фиксированные списки команд, ничего сверх списка.
- Десятки «Джарвисов» на GitHub (Python + Vosk + чат с LLM) и Ирина — либо список команд, либо разговор; агент с руками на рабочем столе и защитой от опасных действий — редкость.
- Голосовые агенты вендоров (ChatGPT с GPT-Live для Codex, Claude Cowork) — официально недоступны в России.
- Claude Code / Codex сами по себе — терминал и клавиатура, голоса нет.

**What it costs them:** время на рутину; для людей с травмами — боль или
невозможность работать; для разработчиков — необходимость сидеть над агентом.

**Emotional tension:** «дать ИИ компьютер страшно — вдруг он что-то купит, удалит
или напишет кому-то»; «голосовые программы всегда не понимают, что я говорю».

## Competitive Landscape
**Direct:** Talon — точный и зрелый, но английский и скриптовый: сначала учишь язык команд.
**Direct (RU):** Ирина (janvarev/Irene-Voice-Assistant, 900+ звёзд, серия на Хабре, офлайн, плагины, LLM через российский сервис-посредник VseGPT — то есть с доступом из РФ) — сильнейший русский конкурент по сообществу; ассистент с плагинами, а не агент, делающий работу на рабочем столе.
**Direct (RU, любительские):** десятки «Джарвисов» на GitHub — AlexMerrys/Jarvis, jsys12/jarvis, RustamovAkrom/JARVIS, NNalyx/j.a.r.v.i.s.-CLI (llama-server + Vosk, видит экран, управляет окнами — ближайший по идее) и др. Обычно ставятся руками через pip, без тестов и без защиты от опасных действий.
**Direct (RU, старые):** Typle, Speechka, «Горыныч», навыки Алисы — только по списку команд.
**Vendor:** ChatGPT desktop с голосом GPT-Live управляет агентами Codex; Claude Cowork управляет компьютером — сильные, но официально недоступны в РФ и не про голосовое управление самим Windows.
**Secondary:** Windows Voice Access — встроен в Windows, но русского нет.
**Indirect:** Claude Code / Codex в терминале, ChatGPT/Claude в браузере — умные, но без голоса и без рук на твоём рабочем столе.

## Differentiation
**Key differentiators:**
- Красные линии в коде, а не в промпте: каждое действие агента проверяется, спорное — вопрос голосом, молчание = «нет». Главное отличие от других «Джарвисов».
- Настоящая работа, а не разговор: Claude Code с 45 инструментами рабочего стола.
- Два уровня: мгновенные команды локально + ИИ-агент для настоящей работы.
- Понимает обычную речь на русском (и английском), а не список команд.
- Распознавание и синтез речи локально; телеметрии нет; ключей API нет.
- Открытый код, установка одной командой.

**How we do it differently:** не учим человека командам — учим программу человеку.
Всё, что можно сделать без модели, делаем без модели (быстро и бесплатно); модель
зовём только для настоящей работы.

**Why that's better:** не нужно учить команды; простое мгновенно; сложное делается
целиком; и это безопасно.

**Why customers choose us:** *гипотеза* — «он спросил перед тем, как пушить» и
«он правда сделал работу, а не поболтал».

## Objections
| Objection | Response |
|-----------|----------|
| «Claude в России недоступен» | Прямые команды работают без подписки и без интернета. Для ИИ-части нужен свой доступ к Claude Code или Codex — многие разработчики им уже пользуются. |
| «Страшно давать ИИ компьютер» | Красные линии проверяются в коде на каждом действии агента; деньги, сообщения людям, системные файлы и опасные команды — только после «да» вслух. |
| «Он будет слушать всё подряд» | Распознавание локальное, на вашем компьютере. В лог не пишется диктовка и речь, обращённая не к Джарвису. Телеметрии нет. |
| «Голосовые программы плохо понимают» | Whisper локально, модель выбирается по мощности компьютера; мишеринги исправляются таблицей; стоп-слова распознаются всегда. |
| «Только Windows?» | Да, рабочий стол — Windows. Разговор и агент работают и на Linux/macOS из исходников. |

**Anti-persona:** ищет болталку или умную колонку; нужен macOS/Linux-десктоп;
хочет, чтобы ИИ-часть была бесплатной без всяких подписок; компании с
требованиями к централизованному управлению.

## Switching Dynamics
**Push:** надоело учить команды / надоели английские инструменты / сидеть над агентом.
**Pull:** говоришь по-русски как человеку; агент делает работу целиком; безопасно.
**Habit:** клавиатура и мышь быстрее для привычного; стыдно говорить с компьютером при людях.
**Anxiety:** «сломает что-нибудь», «не поставится», «не поймёт мой голос», «нужен VPN для Claude».

## Brand Voice
**Tone:** спокойный, честный, чуть самоироничный. Как инженер рассказывает другу.
**Style:** прямо, с цифрами, без маркетинговых суперлативов; говорим, что не работает.
**Personality:** надёжный, внимательный, дерзкий в идее («свой Джарвис»), скромный в обещаниях.

## Proof Points
