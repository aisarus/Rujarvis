# Interpreter marks and distributions

The Apache License 2.0 applies to the source code in this repository. It does
not grant permission to use Open Interpreter names, logos, or other marks to
imply that a modified distribution is an official release.

Unmodified source builds may accurately describe themselves as builds of
Interpreter Workstation. Official release status is established by publication
through the Open Interpreter release workflow and, where applicable, the
project's signing identity.

Materially modified public distributions should use their own application
name, package identifier, icons, update channel, and support links. Accurate
nominative references such as “based on Interpreter Workstation” are welcome.
Organizations may use Interpreter branding internally when it does not imply a
public endorsement or official release.

This policy protects provenance and user trust; it does not reserve client
features or restrict use of the Apache-licensed code.
